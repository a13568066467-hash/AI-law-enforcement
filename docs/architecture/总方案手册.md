## 模块速查

| 模块 | 路径 | 职责 |
|------|------|------|
| 主控 App | `android-app/` | Camera2、按键、扫码出码、SessionManager |
| 手机 App | `mobile-app/` | 登录/注册、扫执法仪码、`bind/confirm` |
| 本机平台 | `android-app/.../platform/` | NativeRecorder、ZE69、RecorderKeyDispatcher |
| 云端 | `backend/` | AI 代理、设备绑定会话、巡查员 MySQL |
| 九大场景 | `android-app/.../demo/` | 演示数据与弹窗 |

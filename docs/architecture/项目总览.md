# 赢筑AI — 项目总览

> **text1** 仓库：DSJ-ZECN6A1 本机 Android 主控 + 云端 AI + MySQL 巡查员库

---

## 1. 产品是什么

**赢筑AI**（DSJ-ZECN6A1 本机 App）— 安装在执法仪上的主控应用，面向工地/执法巡查。

| 功能 | 说明 | 触发 |
|------|------|------|
| **录像** | Camera2 1080p H.264 本地存储 | 录像键 / App / AI 指令 |
| **拍照** | JPEG + AI 识图 | 快门键 / App |
| **AI 助手** | 对话、控设备、追问识图 | AI 页文字（ASR 待做） |
| **巡查员** | 8 步注册、人脸登录 | 我的 |

---

## 2. 技术路线

```
┌──────────────────────┐   HTTPS    ┌─────────────┐    API    ┌──────────┐
│ DSJ-ZECN6A1 + App    │ ◄────────► │  backend/   │ ◄───────► │ 百炼 AI  │
│ Camera2 / 按键 / UI  │            │ FastAPI+MySQL│           │ turbo/VL │
└──────────────────────┘            └─────────────┘           └──────────┘
```

---

## 3. 代码结构

```
text1/
├── android-app/     # Kotlin 主控 App
│   ├── platform/    # NativeRecorder、RecorderKeyDispatcher、ZE69
│   ├── data/        # SessionManager、ApiClient、OfficerProfile
│   └── ui/          # 五 Tab
├── backend/         # 云端 API + 巡查员 MySQL
└── docs/            # 产品/架构文档
```

**会话中心：** `SessionManager.kt` — 本机录像/拍照、云端 API、巡查员状态。

---

## 4. 开发顺序

| 阶段 | 目标 |
|------|------|
| P0 | 本机 Camera2 + 按键 + 相册/录像页 |
| P1 | 巡查员注册/登录 + MySQL |
| P2 | ASR/TTS 真语音 |
| P3 | GB28181 / WebRTC |
| P4 | 系统签名、开机自启、低功耗 |

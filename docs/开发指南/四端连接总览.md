# 四端连接总览

> **范围**：执法仪（设备端）· 手机 App · Web 指挥台 · 后端  
> **默认后端基址**：`http://<主机>:8000`（设备/手机见 `ApiConfig`，Web 见 `VITE_API_BASE`）  
> **实现入口**：`android-app/` · `mobile-app/` · `web-console/` · `backend/`  
> **领域术语**：根目录 [`CONTEXT.md`](../../CONTEXT.md)  
> **扫码细节**：[`设备连接接口.md`](设备连接接口.md) · **全量 HTTP**：[`API接口.md`](API接口.md)

本文说明四端**谁连谁、经什么通道、用哪些接口**。四端之间**没有点对点直连**（手机不连执法仪、Web 不连执法仪 HTTP）；业务都经后端编排，实时音视频经腾讯云 TRTC。

---

## 1. 角色与代码

| 端 | 仓库目录 | 职责摘要 |
|----|----------|----------|
| **设备端** | `android-app/` | 录像/拍照、扫码出码、占用持房、共摄推流、PTT/AI、现场事件上报 |
| **手机端** | `mobile-app/` | 人脸登录/注册、扫码确认占用 |
| **Web 端** | `web-console/` | 设备列表、画面监看、指挥连线、现场事件工单 |
| **后端** | `backend/` | FastAPI + MySQL：认证、占用、会话、UserSig、MQTT 发布、AI 代理 |

外部依赖（非本仓库进程）：

| 外部服务 | 用途 |
|----------|------|
| **EMQX / 阿里云 IoT** | 指挥/监看下行信令 Broker |
| **腾讯云 TRTC** | 监看 / 指挥连线媒体（音视频不经本后端转发） |
| **百炼 Realtime / Chat / Vision** | 设备 AI 助手（经后端代理） |

## 2. 连接全景

```
                    ┌─────────────────────────────────────────┐
                    │              后端 FastAPI               │
                    │         (+ MySQL / 环境配置)            │
                    └───────┬───────────┬───────────┬─────────┘
           HTTPS REST       │           │           │  HTTPS / WSS
        ┌───────────────────┼───────────┼───────────┼───────────────────┐
        │                   │           │           │                   │
        ▼                   ▼           ▼           ▼                   ▼
   ┌─────────┐        ┌─────────┐  ┌────────┐  ┌─────────┐        ┌──────────┐
   │ 手机 App │        │ 执法仪  │  │  Web   │  │ 百炼 AI │        │ 管理入库 │
   │ mobile  │        │ 设备端  │  │控制台  │  │(代理)   │        │(可选)    │
   └─────────┘        └────┬────┘  └───┬────┘  └─────────┘        └──────────┘
                           │           │
              MQTT 信令 ◄──┤           │
              (EMQX/IoT)   │           │
                           │    UserSig│凭证来自后端
                           ▼           ▼
                    ┌──────────────────────┐
                    │   腾讯云 TRTC 房间    │  ← 仅媒体面：设备推 / Web 拉
                    └──────────────────────┘
```

**硬规则**

1. **控制面**：手机 / 设备 / Web → 后端 HTTP(S)。  
2. **信令面**：后端 → MQTT Broker → 设备；设备 HTTP `poll` / `ack` 兜底。  
3. **媒体面**：设备 ↔ TRTC ↔ Web；后端只签发 `sdk_app_id` / `room_id` / `user_id` / `user_sig`。  
4. **手机 ↔ 设备**：无网络直连；靠扫码 URL + 后端占用状态对齐。  
5. **Web ↔ 设备**：无业务 HTTP 直连；画面靠同房 TRTC。

## 3. 通道一览

| 通道 | 端点关系 | 协议 | 典型内容 |
|------|----------|------|----------|
| A. 业务 API | 三端 → 后端 | HTTP/JSON | 登录、绑定、监看/连线会话、工单、设备列表 |
| B. MQTT 信令 | 后端发布 → Broker → 设备订阅 | MQTT | `watch_start` / `call_start` / `end` / 占用房相关 |
| C. HTTP 信令兜底 | 设备 → 后端 | HTTP GET poll + POST ack | 与 MQTT 同语义，需去重 |
| D. TRTC 媒体 | 设备 ↔ Web | 腾讯云 TRTC SDK | 监看只拉视频；连线可推麦/对讲 |
| E. AI Realtime | 设备 → 后端 → 百炼 | WebSocket `/v1/realtime/voice` | PTT 全双工语音（需 `session_token`） |
| F. AI HTTP | 设备 → 后端 | `/v1/chat` `/v1/vision` 等 | 文本/看图（需鉴权） |

## 5. 主流程与接口

### 5.1 扫码占用（手机 ↔ 后端 ↔ 设备）

手机与设备**不同时直连**，时序：

```
设备                         后端                          手机
 │── POST /auth/device/bind/token ──►│                       │
 │◄── token + qr_url ────────────────│                       │
 │   展示二维码                      │                       │
 │── GET .../bind/status 轮询 ───────►│                       │
 │                                   │◄── POST /auth/mobile/login ──│
 │                                   │◄── POST .../bind/confirm ────│
 │◄── status=bound + session_token ──│                       │
 │── ensure 占用房 / MQTT 配置 ──────►│                       │
 │══ MQTT CONNECT ═══════════════════╡ Broker                │
```

| 方法 | 路径 | 调用方 | 作用 |
|------|------|--------|------|
| `POST` | `/auth/device/bind/token` | 设备 | 申请短期扫码 token |
| `GET` | `/auth/device/bind/status` | 设备 | 轮询 pending/bound/expired |
| `POST` | `/auth/mobile/login` | 手机 | 人脸登录，拿 Bearer |
| `POST` | `/auth/mobile/register` | 手机 | 注册（含人脸模板） |
| `POST` | `/auth/device/bind/confirm` | 手机（Bearer） | 扫码确认占用 |
| `POST` | `/auth/device/bind/release` | 设备 | 主动解绑 |
| `POST` | `/auth/device/bind/shutdown` | 设备 | 关机/重启结束占用 |
| `PATCH` | `/v1/recorders/{device_id}/company` | 管理/运维 | 设备入库绑公司 |

字段级契约见 [`设备连接接口.md`](设备连接接口.md)。

---

### 5.2 占用持房 + 画面监看 / 指挥连线（Web ↔ 后端 ↔ 设备 ↔ TRTC）

```
占用成功后：
  设备 ── POST /v1/command-call/occupancy-room/ensure ──► 后端签发 room + 设备 UserSig
  设备 ── TRTC enterRoom（占坑，默认可不推流）──► 腾讯云
  设备 ── POST .../occupancy-room/ready + join-ack ──► 后端（房间就绪）

Web 点选监看：
  Web ── POST /v1/command-call/watch/start ──► 后端（同 room，签平台 UserSig）
  后端 ── MQTT start（或设备 poll 拉到）──► 设备开始共摄推流
  Web ── TRTC enterRoom（只拉视频）──► 腾讯云
  Web ── POST .../watch/heartbeat（约 10s）──► 后端保活

升级 / 冷启动连线：
  Web ── POST .../upgrade 或 /v1/command-call/start ──► 后端
  同房升麦；设备进连线态（对讲/红灯/打断 AI）
```

#### Web → 后端

| 方法 | 路径 | 作用 |
|------|------|------|
| `GET` | `/v1/dashboard/devices` | 设备列表（含 `inUse` / `roomReady`） |
| `POST` | `/v1/command-call/watch/start` | 开始画面监看 |
| `POST` | `/v1/command-call/{call_id}/watch/heartbeat` | 监看心跳 |
| `POST` | `/v1/command-call/{call_id}/watch/end` | 结束监看 |
| `POST` | `/v1/command-call/{call_id}/upgrade` | 监看升级为连线 |
| `POST` | `/v1/command-call/start` | 冷启动指挥连线 |
| `GET` | `/v1/command-call/{call_id}` | 查询会话 |
| `POST` | `/v1/command-call/{call_id}/end` | 结束连线 |

Web 进房参数取自响应里的 `platform`：`sdk_app_id` / `room_id` / `user_id` / `user_sig`（`web-console/src/api.ts` + TRTC Web SDK）。

#### 设备 → 后端（持房 / 信令）

| 方法 | 路径 | 作用 |
|------|------|------|
| `GET` | `/v1/mqtt/client-config?device_id=` | 拉 Broker 参数 |
| `POST` | `/v1/command-call/occupancy-room/ensure` | 占用侧要房 |
| `GET` | `/v1/command-call/device/{id}/occupancy-room` | 查占用房凭证 |
| `POST` | `/v1/command-call/device/{id}/occupancy-room/ready` | 上报房间就绪 |
| `POST` | `/v1/command-call/occupancy-room/join-ack` | 确认已进占用房 |
| `GET` | `/v1/command-call/device/{id}/poll` | HTTP 兜底拉 start/end 等 |
| `POST` | `/v1/command-call/{call_id}/device-ack` | 确认已消费业务 start |
| `GET` | `/v1/command-call/device/{id}/active` | 查设备活跃会话 |

#### MQTT（后端 → 设备）

| 项 | 现行联调（EMQX） |
|----|------------------|
| 配置下发 | `GET /v1/mqtt/client-config` |
| 订阅 | `{topic_prefix}/{deviceId}/start`、`.../end` |
| 载荷 | 与 poll 一致：`watch_start` / `call_start` / `call_upgrade` / `occupy_room` / `*_end` 等 |
| 兜底 | MQTT 未配置或断线时仍靠 `poll` |

### 5.3 现场事件工单（设备上报 · Web 处置）

```
设备（SOS 松手）── POST /v1/field-event-tickets ──► 后端
Web ── GET /v1/field-event-tickets?company= ──► 后端
Web ── PATCH /v1/field-event-tickets/{id} ──► 改状态
```

| 方法 | 路径 | 调用方 |
|------|------|--------|
| `POST` | `/v1/field-event-tickets` | 设备（占用会话 / Bearer） |
| `GET` | `/v1/field-event-tickets` | Web（按公司） |
| `GET` | `/v1/field-event-tickets/{id}` | Web |
| `PATCH` | `/v1/field-event-tickets/{id}` | Web |

### 5.4 设备 AI（设备 ↔ 后端 ↔ 百炼）

| 通道 | 路径 | 说明 |
|------|------|------|
| Realtime | `WS /v1/realtime/voice` | 需 `Authorization: Bearer <session_token>`；后端桥接百炼 |
| Chat | `POST /v1/chat` | 文本对话 |

## 6. 按端汇总：各自连什么

### 6.1 设备端（`android-app`）

| 目标 | 怎么连 | 主要接口 / SDK |
|------|--------|----------------|
| 后端 | HTTPS（`ApiClient`） | bind / mqtt-config / occupancy / poll / ack / field-event / AI |
| MQTT Broker | TCP MQTT（`MqttClient`） | `GET /v1/mqtt/client-config` 后 CONNECT + SUB |
| TRTC | 腾讯云 Android SDK | 占用进房；监看/连线共摄旁路推视频 |
| 手机 / Web | **不直连** | 经后端状态 + TRTC 房间 |

### 6.2 手机端（`mobile-app`）

| 目标 | 怎么连 | 主要接口 |
|------|--------|----------|
| 后端 | HTTPS（`ApiClient`） | `POST /auth/mobile/login`、`/register`、`/auth/device/bind/confirm` |
| 设备 | 仅扫码读 `qr_url` | 无 Socket / 无设备 HTTP |
| Web / TRTC | **不使用** | — |

### 6.3 Web 端（`web-console`）

| 目标 | 怎么连 | 主要接口 / SDK |
|------|--------|----------------|
| 后端 | `fetch` → `VITE_API_BASE` | dashboard、command-call、field-event-tickets |
| TRTC | `trtc-sdk-v5` | 用后端下发的 `platform` 凭证进房 |
| 设备 / 手机 | **不直连** | 列表与会话状态来自后端 |

### 6.4 后端（`backend`）

| 目标 | 怎么连 | 说明 |
|------|--------|------|
| 三端客户端 | 暴露 REST / WS | FastAPI routers |
| MySQL | 同步/异步访问 | 档案、占用、工单等 |
| MQTT Broker | HTTP API 发布（EMQX）或 IoT Pub | 不经客户端中转 |
| TRTC | 仅本地签 UserSig | SecretKey 不下发 |
| 百炼 | HTTPS / 上游 WSS | AI 代理 |

## 7. 鉴权摘要

| 调用方 | 鉴权 |
|--------|------|
| 手机登录/注册 | 无 → 响应 Bearer |
| 手机 `bind/confirm` | `Authorization: Bearer <mobile_token>` |
| 设备 bind token/status/release | 当前联调多为无 Bearer；绑定成功后拿 `session_token` |
| 设备 AI / 部分业务 | `session_token`（占用会话） |
| Web 指挥台 API | 当前联调多为无鉴权（生产应补） |
| MQTT 设备连接 | Broker 用户名密码（或 IoT 三元组） |
| TRTC | 后端签发短时 UserSig |

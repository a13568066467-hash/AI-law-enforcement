# ESP32-S3 固件开发指南

> 技术路线：**ESP-IDF 5.x + C** · 对接 Android · 协议见 [BLE协议.md](./BLE协议.md)

---

## 一、开发环境（Windows）

### 1. 安装 ESP-IDF

1. 下载 [ESP-IDF Windows 安装器](https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/get-started/windows-setup.html)
2. 选择 **ESP-IDF v5.2+**，勾选 **esp32s3**
3. 安装完成后打开 **「ESP-IDF 5.x CMD」** 或 **「ESP-IDF PowerShell」**（自带 `IDF_PATH`）

### 2. 验证

```bash
idf.py --version
echo %IDF_PATH%
```

### 3. 连接开发板

- USB 接 **Seeed XIAO ESP32S3** 的 USB-C 口（或 DevKitC 备用板）
- 设备管理器查看 COM 口（如 `COM3`）

## 二、工程结构

```
firmware/
├── CMakeLists.txt
├── sdkconfig.defaults      # S3、BLE、PSRAM、FSM 自测、相机/双麦
├── idf_component.yml
└── main/
    ├── CMakeLists.txt
    ├── main.c              # app_main 入口
    ├── app_fsm.c           # 状态机（录像/识图/AI）
    ├── button.c            # 三键扫描
    ├── ble_service.c       # NimBLE GATT（A001~A008 子集）
    ├── camera.c            # OV5640 JPEG 拍照
    ├── audio_in.c / audio_out.c / audio_i2s.c / audio_prompt.c
    ├── power_mgr.c         # ADC 电量、充电检测
    ├── standby_mgr.c       # 待机、AI 空闲关麦
    ├── board_selftest.c    # 引脚/模块自检
    └── include/
        ├── board_config.h
        ├── camera_pins.h
        ├── app_fsm.h
        └── ble_service.h
```

## 三、编译与烧录

在 **ESP-IDF 终端** 中：

```bash
cd firmware
idf.py set-target esp32s3
idf.py build
idf.py -p COM3 flash monitor
```

`Ctrl+]` 退出 monitor。

**常用命令：**

```bash
idf.py fullclean          # 清构建
idf.py menuconfig         # 图形配置（相机引脚等）
idf.py erase-flash        # 擦除 Flash
```

## 四、代码怎么写（分层思路）

```
app_main()
    ├── NVS、app_fsm_init() [可选 FSM 自测]
    ├── audio_out/in_init()
    ├── camera_init()         ← OV5640 JPEG
    ├── ble_service_init()    ← NimBLE GATT
    ├── button_init()         ← GPIO → FSM 事件
    ├── power_mgr_init() / standby_mgr_init()
    └── board_selftest_run()
```

**原则：**

1. **驱动层** 只负责硬件（GPIO、I2S、camera、BLE）
2. **状态机** 只负责业务（`app_fsm_handle_event`）
3. **Android 命令** 在 `ble_service.c` 里解析后，转成 `EVT_VOICE_*` 等事件交给 FSM

## 六、分阶段写代码

### 阶段 1 — 相机（优先）

1. 从 ESP-IDF 复制 camera 例程配置：

```bash
# 参考路径（随 IDF 版本略有不同）
%IDF_PATH%\examples\peripherals\camera\...
```

2. 新建 `main/camera.c`，用 **esp_camera**：

```c
esp_err_t camera_init(void);
esp_err_t camera_capture_jpeg(uint8_t **buf, size_t *len);
esp_err_t camera_start_record(void);
esp_err_t camera_stop_record(void);
```

3. 引脚以 `camera_pins.h`（XIAO Sense OV5640 扩展座）为准；`menuconfig` 选 **OV5640**

4. 在 `app_fsm_on_shutter_click()` 里调用 `camera_capture_jpeg()`

### 阶段 2 — BLE

1. 参考 `%IDF_PATH%\examples\bluetooth\nimble\bleprph`
2. 新建 `ble_service.c`，注册 Service `0000A001-...`
3. 实现 Characteristic：CMD_WRITE、IMAGE_TX、AUDIO_TX 等
4. Android 连上后，JPEG 按 512B 分片从 IMAGE_TX 发出

### 阶段 3 — 音频

1. I2S 标准模式读 INMP441
2. 集成 **libopus**（ESP-IDF component 或 idf component registry）
3. 16 kHz mono，20 ms 帧，写入 AUDIO_TX

### 阶段 4 — 录像 + OTA

1. MJPEG 写 SPIFFS/FAT 分区
2. 停止后通过 VIDEO_TX 传 App
3. OTA 用 `esp_https_ota`（V1.1）

## 七、引脚表（board_config.h）

| 功能 | GPIO |
|------|------|
| 电源 / 快门 / AI | 1 / 2 / 3 |
| I2S BCK / WS / 双麦 DIN / 喇叭 DOUT | 6 / 43 / 44 / 8 |
| 功放 DIN | 8 |
| 电池 ADC / CHRG | 4 / 5 |
| IMU I2C（可选） | 21 / 9 |
| OV5640（扩展座） | 见 `camera_pins.h` |

**勿插 MicroSD**（与双麦争用 GPIO7/8/9）。详见 [XIAO硬件接线.md](./XIAO硬件接线.md)。

## 八、与 Android 的接口

固件 **不调用阿里云**；只实现 [BLE协议.md](./BLE协议.md)：

- App 写 `CMD 0x04` → 设备开始推 Opus（AI 聆听）
- App 写 `AUDIO_RX` → 设备播放 TTS
- 设备 NOTIFY `0x83 CAPTURE_DONE` → App 收 IMAGE_TX

## 九、调试技巧

| 问题 | 方法 |
|------|------|
| 编译找不到 IDF | 必须用 ESP-IDF 专用终端 |
| 烧录失败 | 按住 BOOT，点 RESET，再 flash |
| 按键无反应 | 万用表测 GPIO，按下应为 0V |
| 相机 init fail | 查 3.3V、排线、SCCB 4/5 |
| BLE 连不上 | 手机开定位+蓝牙权限，看 NimBLE 日志 |

# 专机锁定：软锁 + ROM 级，不用 Lock Task

量产执法仪要以「开机即进本 App、日常进不了系统设置」保证侧键无障碍不被关掉。备选是 App 内 Lock Task / Device Owner（硬锁），或软锁（HOME + 禁厂商桌面）叠加 ROM 去掉状态栏/设置等出口。我们选 **软锁 + ROM 级**：App 侧只做专机桌面与预装/无障碍默认开启；挡系统出口交给致业 ROM，避免与厂商 MDM/按键栈叠两套锁定机制。在 ROM 未交付前，仅靠软锁仍可能摸到设置，属已知空窗。**未绑定人员**时允许「我的 → 设置 → 解绑」连续点 7 次进入系统桌面，作为软锁维保出口；已绑定则关闭该出口（解绑走正常释放占用）。

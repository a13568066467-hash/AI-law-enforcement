# 指挥连线媒体采用腾讯云 TRTC，替代自建 WebRTC

专家/指挥中心与执法仪的实时音视频原规划为自建 `google-webrtc` P2P；现改为腾讯云 TRTC 承载媒体，本系统仅自建 MQTT（+HTTP 兜底）连线信令与 UserSig 签发。连线信令仅为平台→设备的呼叫开始与结束连线；设备默认自动接听并进房，不发送应答、忙线或挂断等上行控制态。原因是执法仪需与本机录像共摄、半双工 PTT、占用会话强绑定，自建 WebRTC 在 STUN/TURN、弱网与工程成本上不划算；TUICallKit 整包信令又难以嵌入上述约束。GB28181 国标监控通道保持独立，不由 TRTC 替代。

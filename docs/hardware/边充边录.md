# 充电与边充边用

> 硬件：TP4056 Type-C 充保模块 + 2000mAh 锂电（见 `已购硬件.md`）

## 支持能力（V1）

| 场景 | 行为 |
|------|------|
| **边充电边录像** | 插入 USB 充电时，**允许**新开始录像（即使电量 ≤10%） |
| **边充电边 AI** | 同上，允许开 AI 聆听 |
| **低电保护** | 充电中**不**因 ≤10% 强制 `EVT_LOW_BATTERY` 停录/停 AI |
| **低电提醒** | ≤15% 仍可喇叭提醒（建议工人知悉，但不打断业务） |
| **轻睡眠** | 充电中**不**进入 `standby` 轻睡眠 |
| **App 显示** | BLE `SENSOR_NOTIFY` FLAGS **bit0=1** 表示充电中 |

## 硬件接线

```
TP4056 模块
  BAT+ / BAT-  → 电池（与设备负载并联）
  OUT+ / OUT-  → ESP32-S3 系统 3.3V 供电（经既有 LDO/升压）
  CHRG 引脚    → ESP32 GPIO5（XIAO D4，内部上拉，低电平=充电中）
  GND 共地
```

| 引脚 | `board_config.h` |
|------|------------------|
| CHRG | `PIN_CHARGE_DETECT` = **GPIO5**（XIAO D4） |
| 有效电平 | `CHARGE_DETECT_ACTIVE_LOW` = 1（TP4056 典型） |

> 若模块为 **STDBY** 高电平表示充满，可另接 GPIO 扩展「已充满」；V1 仅检测「正在充电」。

## 固件配置（menuconfig）

| 配置 | 默认 | 含义 |
|------|------|------|
| `CHARGE_DETECT_ENABLE` | y | 读 CHRG GPIO |
| `CHARGE_ALLOW_RECORD_WHILE_PLUGGED` | y | 边充边录/AI |
| `CHARGE_SKIP_LOW_PROTECT` | y | 充电时不低电强制 idle |
| `CHARGE_USE_MOCK` | n | 无接线时模拟插电 |

模块：`power_mgr.c`（充电+电量）、`standby_mgr.c`（充电不休眠）。

## BLE

见 [`BLE协议.md`](./BLE协议.md) SENSOR_NOTIFY：

```
[BATTERY:1B][STATE:1B][FLAGS:1B]
FLAGS bit0 = charging
```

## 注意

1. **边充边录**会增加发热与充电时间，长时间建议通风、避免暴晒闭盖充电（见 [总方案手册.md](./总方案手册.md) §4 热设计）。  
2. **仅 USB 供电调试**（无电池）时 CHRG 可能常亮，行为等同「充电中」。  
3. App `apptext` 首页可显示「充电中」图标（解析 FLAGS bit0）。

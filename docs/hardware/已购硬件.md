### 3.2 双麦与 SD 卡互斥（不变）

## 七、推荐上电顺序

```
1. 只接 XIAO USB → 烧录 firmware，串口 FSM 自测 17/17
2. 扣上 OV5640 扩展模组（114993115）→ 相机自检 JPEG
3. 面包板接三键 → GPIO 1/2/3 对 GND
4. 接 INMP441 #1 + MAX98357 + 喇叭（8Ω 1W）
5. 接 INMP441 #2（两路 SD 并接 GPIO44；勿插 SD 卡）
6. 焊分压：200k/100k → GPIO4；TP4056 CHRG → GPIO5
7. （可选）IMU660RA → I2C 21/9
8. 最后接 2000mAh 电池（先测 TP4056 充电电流正常）
```

## 九、总结

| 类别 | 结论 |
|------|------|
| **核心已齐** | XIAO Sense、OV5640 扩展、双麦、功放、喇叭、电池、充电、按键、线材 |
| **工具已齐** | 面包板、杜邦线、焊枪、焊条、松香、电笔、热缩管、导热垫 |
| **最关键缺口** | 多半只剩 **分压电阻 200k+100k**、确认 **USB-C 数据线** |
| **建议补** | LED+330Ω、气凝胶隔热、胸牌壳/胸挂（后期） |
| **备用库存** | 裸模组、裸 OV5640、MPU6050、第二块 MAX98357 |

**一句话：** 主链路硬件 **已基本到齐**；补两根分压电阻（和确认数据线）即可在面包板上 **烧录 → 扣相机 → 接麦 → 联调 BLE**。

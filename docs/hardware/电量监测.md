# 低电量监测与语音提醒



## 放电时的行为顺序（先提醒，后禁开录）



电量**从高往低**下降时，两级阈值依次生效（默认配置）：



| 顺序 | 电量 | 行为 | 仍可做什么 |

|------|------|------|------------|

| ① | **≤15%** | 喇叭**提醒**（每 120s 可重复）；BLE `0x86` | 可录像、可 AI、可拍照 |

| ② | **≤10%** | **禁止新开始**录像与 AI；首次进入触发 FSM 停录/停 AI | 仍可**单击拍照**、长按关机 |



> **配置要求：** `BATTERY_LOW_ALERT_PERCENT` **必须大于** `BATTERY_RECORD_MIN_PERCENT`，否则编译报错。



## ADC + 分压（硬件）



| 项目 | 说明 |

|------|------|

| 采样 | 默认每 **5s** `ADC1` 读 **GPIO4**（XIAO D3） |

| 分压 | 电池+ → **R1 200kΩ** → GPIO4 → **R2 100kΩ** → GND |

| 映射 | 3.0V～4.2V → 0%～100%（见 `board_config.h`） |



```

电池+ ── R1 200kΩ ──┬── GPIO4 (ADC1_CH3)

                   │

                  R2 100kΩ

                   │

                  GND（与板共地）

```



- 满电 4.2V → ADC 约 2.8V（< 3.3V，安全）

- **勿**把电池直接接 GPIO



固件模块：`power_mgr.c`、`audio_prompt.c`、`ble_service.c`（SENSOR_NOTIFY / LOW_BATTERY）。

## 开发板 / 硬件是否支持？



| 硬件 | 电量检测 | 本地语音提醒 |

|------|----------|--------------|

| ESP32-S3 | ✅ 片内 ADC | ✅ I2S → MAX98357 |

| 3.7V 锂电 + 保护板 | ✅ 需分压接 ADC | — |

| MAX98357 + 喇叭 | — | ✅ |



未接分压时可用 **模拟电量**（menuconfig → `Use mock` → `MOCK percent = 12` 听 15% 档提醒，`9` 测 10% 保护）。



---



## 配置项（menuconfig）



| 配置 | 默认 | 含义 |

|------|------|------|

| `BATTERY_LOW_ALERT_PERCENT` | **15** | **较高**阈值：语音提醒 |

| `BATTERY_RECORD_MIN_PERCENT` | **10** | **较低**阈值：禁开录/禁 AI + FSM 保护 |

| `BATTERY_ALERT_INTERVAL_SEC` | 120 | 重复提醒间隔 |

| `BATTERY_SAMPLE_PERIOD_MS` | 5000 | ADC 周期 |

| `BATTERY_USE_MOCK` | n | 无分压时模拟电量 |



改 `sdkconfig.defaults` 后建议 `idf.py fullclean build`，或 menuconfig 保存使 `sdkconfig` 与默认一致。

## 串口示例



**15% 档（仅提醒）：**



```

W (power) battery low 14% — voice alert

I (audio_out) play low battery synth ...

```



**10% 档（保护 + 提醒）：**



```

W (power) battery protect 9% — stop record/AI

W (app_fsm) low battery — forced idle

I (ble) BLE NOTIFY 0x86 LOW_BATTERY percent=9

```

## 充电时（边充边录）

# ZE69 / DSJ-ZECN6A1 驱动控制接口
# 与代码 Ze69SysfsPaths.kt 路径常量一一对应
# 写入 sysfs 需系统签名或 root；Debug 包在真机上会静默失败并打日志

基路径：/sys/devices/platform/odm/odm:camera_als

## 三色灯（写 0 关闭，写 1 打开）

红灯： rgb_red_led
绿灯： rgb_green_led
蓝灯： rgb_blue_led

## 红绿灯（写 0 关闭，写 1 打开）

红灯： rg_red_led
绿灯： rg_green_led

## 镭射灯（写 0 关闭，写 1 打开）

leise_led

## 红外灯（写 0 关闭，写 1~255 控制亮度）

ir_led

## 红外 IR_CUT（写 0 关闭，写 1 打开）

ir_door

## 光感值（只读）

als_data

## App 映射（见 Ze69Hardware / NightVisionController）

| 业务状态     | sysfs 组合                          |
|--------------|-------------------------------------|
| 录像指示     | rg_green=1, rg_red=0                |
| AI 聆听      | rgb_blue=1                          |
| 低电量警示   | rgb_red=1                           |
| 夜视开启     | ir_door=1 + ir_led=1~255（光感触发）|
| 复位全部     | 上述全部关闭                        |

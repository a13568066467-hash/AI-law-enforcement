# DSJ-ZECN6A1 物理按键与状态灯

> **厂商《按键操作说明》** + ROM `mtk-kpd.kl` / `gpio-keys.kl`  
> 代码：`RecorderKeyDispatcher.kt`、`DeviceStatusIndicator.kt`

---

## 1. 机身按键（说明书 §二）

| 机身键 | KeyCode | 操作 | App 行为 |
|--------|---------|------|----------|
| **开关键** | POWER | 长按开/关机；短按亮/灭屏 | 系统处理 |
| **录音键** | **F2** | 短按 | 开始/停止 **纯音频** 录音（M4A） |
| **录像键** | **F5** | 短按 | 开始/停止 **视频** 录像（1080p MP4） |
| **拍照键** | **F4** | 短按 | 拍照 → 相册 |
| **PTT 键** | **F6** | **短按** | 白光灯开/关 |
| **PTT 键** | **F6** | **长按** | 对讲演示（AI 聆听蓝灯） |
| **SOS 键** | **F3** | **短按** | **重点标记** 当前/最近录像 |
| **SOS 键** | **F3** | **长按** | SOS 应急演示 |

顶部 **SOS/重点标记**、侧 **对讲 PTT**、**拍照**、**录音**、**录像** 与上表对应。

---

## 2. 状态指示灯（说明书 §三）

| 设备状态 | 指示灯 | 代码 |
|----------|--------|------|
| 待机 | **绿灯常亮** | `DeviceStatusIndicator` standby |
| 录音 | **黄灯闪烁** | 红+绿同闪 |
| 录像 | **红灯闪烁** | `rg_red` 闪烁 |
| 拍照 | **红灯闪一次** | `pulsePhotoCapture()` |
| 充电中 | **红灯常亮** | 电池广播 |
| 充满电 | **绿灯常亮** | 电池广播 |

Debug 包无系统签名时灯可能不亮，功能仍可用。

---

## 3. 红外 / 夜视

**不自动开启红外。** 已关闭 ALS 光感自动夜视（`NightVisionController`）。  
`Ze69Hardware.setNightVision()` 也会强制写关闭值，**未绑定侧键**。

---

## 4. 使用前提

1. **亮屏时**：App 在前台即可响应侧键（`MainActivity.dispatchKeyEvent`）。
2. **息屏 / 后台时**：须在系统设置开启无障碍服务 **「执法仪侧键」**（`RecorderKeyAccessibilityService`），否则侧键无效。
3. 相机/麦克风权限已授予。
4. 录像期间前台服务保持 Camera2 管线；息屏拍照同样经 camera 前台服务短时保活。
5. 同一时刻勿同时录像+录音；**录像中按拍照键**会提示先停止录像。

---

## 5. 与旧版差异

| 旧实现 | 现对齐说明书 |
|--------|--------------|
| F2、F5 都当录像 | **F2=录音，F5=录像** |
| SOS 仅长按 | **短按=重点标记，长按=SOS** |
| PTT 按住=AI 聆听 | **短按=白光灯，长按=对讲** |
| 录像绿灯常亮 | **录像红灯闪** |
| 光感自动红外 | **已关闭** |

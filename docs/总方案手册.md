> **怎么用本文档：** 从上往下读一遍建立全局图；做某一层时跳到对应「模块卡片」；拿不准时看「引导思路」和「常见误区」。  
> 细节协议仍以专项文档为准；本文是 **索引 + 备注 + 决策引导**，不替代 `BLE协议.md` 等。

1. **设备只采集和播放，手机是网关，聪明在公司云上。**

## 1. 引导思路：怎么推进才不乱

### 1.1 一条主链路，不要三线并行

```
P0 后端骨架 → P1 BLE+拍照 → P2 AI 音频闭环 → P3 识图播报 → P4 录像 → P5 语音控设备 → P6 运维
```

**原则：** 未通 P1「手机收到一张真图」前，不要全力做 P4 录像或 Opus 优化。  
**无硬件时：** `demo-web/` 验证交互；`python tools/fsm_host_test.py` 验证 FSM。

### 1.2 两个中心，模块不要绕路

| 中心 | 位置 | 规则 |
|------|------|------|
| **固件 FSM** | `firmware/main/app_fsm.c` | 按键、BLE CMD → `app_fsm_handle_event()`；录像/AI/拍照互斥在此 |
| **App 会话** | `apptext/services/session.uts` | 页面只调 session；BLE + `/v1/chat` + `/v1/vision` 都经此层 |

### 1.3 问需求时先问「落在哪一层」

| 工人/产品说的话 | 先想 |
|-----------------|------|
| 「识图不准」 | 云端 VL prompt / 拍照清晰度 / 光线，不是先改 FSM |
| 「连不上」 | BLE GATT、Android 权限、固件 `ble_service.c` |
| 「耗电快」 | `standby_mgr`、边充边录时长、散热通风 |
| 「低电不能录」 | `power_mgr`；充电中见 `边充边录.md` |

### 1.4 当前整体进度（粗估）

| 板块 | 完成度 | 说明 |
|------|--------|------|
| 方案与文档 | ~100% | 本文 + 专项 doc |
| 固件底座 | ~65% | FSM/按键/电量/待机/BLE GATT/相机 JPEG ✅；Opus/录像 MJPEG 🔲 |
| App `apptext` | ~45% | 五页+session/BLE 连接/识图回调 ✅；Opus/TTS/录像 🔲 |
| 云端后端 | ~70% | `backend/` login/chat/vision mock+百炼 ✅；ASR/TTS/WSS 🔲 |
| 端到端 MVP | ~30% | 待实机联调 JPEG+vision 全链路 |

### 3.2 固件 `firmware/`

| 子模块 | 文件 | 状态 | 备注 / 引导思路 |
|--------|------|------|-----------------|
| **入口** | `main.c` | ✅ | 顺序：NVS → FSM[自测] → audio → camera → **ble** → button → power → standby → selftest |
| **FSM 中心** | `app_fsm.c` | ✅ | 所有业务状态在此；新增功能先加 `glass_event_t`，勿在 button 里直接改相机 |
| **按键** | `button.c` | ✅ | 电源松开判长按 3s；AI 双击=两次松开；注意上电误触已修 |
| **电量** | `power_mgr.c` | ✅ | 先 ≤15% 提醒，再 ≤10% 禁录；ADC **GPIO4** + 200k/100k 分压 |
| **充电** | `power_mgr` + `边充边录.md` | ✅ | CHRG→**GPIO5**；**边充边录**；充电中不低电强停 |
| **待机续航** | `standby_mgr.c` | ✅ | AI 5s 无活动关麦；空闲可轻睡眠；充电不休眠 |
| **喇叭** | `audio_out.c` | ✅ | MAX98357 BCK6/WS43/DIN8；低电合成音 |
| **BLE 服务** | `ble_service.c` | ✅ | NimBLE + A001/A002/A003/A006/A008；JPEG 分片；待实机联调 |
| **相机** | `camera.c` | 🟡 | OV5640 JPEG 拍照 ✅；MJPEG 录像 🔲 |
| **采麦 Opus** | `audio_in.c` | 🟡 | 双麦立体声+简易降噪 ✅；Opus→`AUDIO_TX` 🔲 |
| **引脚** | `board_config.h` · `camera_pins.h` | ✅ | XIAO：按键 1/2/3；双麦 6/43/44/7；OV5640 扩展座 |

**烧录：** `cd firmware` → `idf.py build flash monitor`（ESP-IDF 终端）  
**自测：** `CONFIG_FSM_SELF_TEST` → 串口 17/17；主机 `tools/fsm_host_test.py`

**常见误区：** 在模组里调百炼 API；在 CAPTURE 状态绕过 FSM 开录像。

### 3.3 手机 App `apptext/`（HBuilderX · uni-app x）

| 子模块 | 路径 | 状态 | 备注 / 引导思路 |
|--------|------|------|-----------------|
| **页面** | `pages/index|chat|album|video|settings` | ✅ 壳 | Tab 五页；业务逻辑勿写进 `.uvue`，放 `services/` |

| **BLE** | `services/ble.uts` | 🟡 | 扫描/连接/notify/分包/写 CMD ✅；待实机验证 |
| **云端 API** | `services/api.uts` | 🟡 | login、`/v1/chat`、`/v1/vision`；改 `common/config.uts` 域名 |

### 3.4 云端后端 `backend/`

| 子模块 | 职责 | 状态 | 备注 / 引导思路 |
|--------|------|------|-----------------|
| **鉴权** | `POST /auth/login` | ✅ | 演示 13800000000/demo |

**常见误区：** 让 App 直连百炼；Agent-B 输出 `start_recording` 等控制 intent。

### 3.5 连接协议 `docs/BLE协议.md`

| 特征 | 用途 | 引导 |
|------|------|------|
| A002 CMD_WRITE | App→设备 控制 | 0x01 开录 … 0x05 停 AI |
| A003 NOTIFY | 设备→App 事件 | 0x83 拍照完成、0x86 低电 |
| A004/A005 | Opus 麦 / TTS | P2 |
| A006/A007 | 图 / 录像分片 | P1 / P4 |
| A008 SENSOR | 电量+状态+FLAGS | bit0 充电中 |

**原则：** 大包必须分片；`STATE=RECORD` 时 App 慎发 `START_AI_LISTEN`。

### 3.6 AI 与识图 `docs/云端AI代理.md`

| 能力 | 模型 | 备注 |
|------|------|------|
| 控制+短答 | `qwen-turbo` Agent-A | intent JSON → `ble_cmds` |
| 追问上图 | `qwen-turbo` Agent-B | 仅用 `last_explanation`，禁止编造读数 |
| 拍图解释 | `qwen3-vl-8b-instruct` | **不是 YOLO**；云端 VLM 看图说话 |

**对外说法：** 「识别算法是云端视觉语言模型，设备只拍照上传。」

**若改 YOLO：** 见此前架构讨论——改 `/v1/vision` 管线，不是只换 model 字符串。

## 4. 热设计采购方案（边充边录）

> **思路：** 内部**散热**，贴胸**隔热**，外壳**通风**；不用保温棉填满机壳。

| 类别 | 建议采购 | 备注 |
|------|----------|------|
| 散热 | 导热硅胶垫 1mm + 14×14 铝散热片 | 贴 ESP32 模组金属面 |
| 隔热 | 气凝胶/硅胶垫 1~3mm | **电池与主板之间** |
| 胸挂 | 背胶硅胶垫 2~5mm | 外壳贴胸侧，防烫 |
| 结构 | 3D 外壳侧面 φ2~3mm 通风孔 ×4 | 充电口附近留风道 |
| 可选 | NTC 10K + 石墨散热膜 | 量产前温控告警 |

**使用：** 边充边录可行，但避免暴晒闭盖；连续高负载录 15~20 min 建议歇停。

## 5. 里程碑与验收（按阶段）

| 阶段 | 验收标准 | 依赖模块 |
|------|----------|----------|
| **P0** | App 带 token 调通 `/v1/chat` mock | 后端、api.uts |
| **P1** | 手机相册收到 **1 张** JPEG | ble_service、camera、ble.uts |
| **P2** | 双击 AI 对话+播报 | audio_in、Opus、ASR/TTS |
| **P3** | 快门后听识图解释 | `/v1/vision`、VL |
| **P4** | 720p 录 5 min 不崩 | MJPEG、VIDEO_TX |
| **P5** | 「开始录像」语音执行 | Agent-A intent |
| **P6** | 项目部绑定/额度/日志 | ToB 后台 |

**MVP 工人路径验收：** 登录 → 连蓝牙 → 快门识图播报 → 语音开停录 → 相册回放。

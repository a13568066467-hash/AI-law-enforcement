# 连线房间由设备占用侧持有，Web 进房接听

原模型由平台在画面监看/指挥连线开始时建房并下发进房，设备被动进房，易出现 Web 已进房而设备仍 `connecting`、画面黑屏。现改为占用成立后可签发占用侧房间与 UserSig（兼容路径）；**新媒体主路径见 ADR-0005 公司任务房**——多设备与多座席同 TRTC 房。解绑作废占用并移出任务房。Web 点选可加入任务房只看（不开麦），升麦或冷启动连线为同房升麦；推流以 TRTC 远端进/退房为主、本系统信令兜底。建房失败不否定占用；以房间就绪、心跳与无流超时防止业务僵尸房。常驻监控墙仍归 GB28181。媒体仍为 TRTC，SecretKey 仍仅存后端。

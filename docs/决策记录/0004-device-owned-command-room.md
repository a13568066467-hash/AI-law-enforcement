# 连线房间由设备占用侧持有，Web 进房接听

原模型由平台在画面监看/指挥连线开始时建房并下发进房，设备被动进房，易出现 Web 已进房而设备仍 `connecting`、画面黑屏。现改为：**一占用一房**——占用成立后后端签发房间与 UserSig，设备进房占坑；解绑作废。Web 点选加入已有房间只看（不开麦），升级或冷启动连线为同房升麦；推流以 TRTC 远端进/退房为主、本系统信令兜底。监看/连线仍保留独立业务会话（互斥、心跳、审计）。建房失败不否定占用；以房间就绪、心跳与无流超时防止业务僵尸房。不引入多路旁听或常驻监控墙（仍归 GB28181）。本决策修订 ADR-0002/0003 中「平台发起进房」的表述，媒体仍为 TRTC，SecretKey 仍仅存后端。

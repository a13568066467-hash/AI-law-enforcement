# 公司任务房承载多设备与多座席 TRTC

原模型为「一占用一 TRTC 房、一座席互斥（监看 XOR 连线）」，无法同房多台执法仪或多座席协同。现改为：**公司任务房**——同公司下按需创建任务房，签发统一 `trtc_room_id`；已占用且在线的多台设备与多个 Web 座席加入同一房间。人机扫码占用仍决定「谁在用哪台机、是否同公司」；媒体进房改走任务房。座席默认可多人开麦（TRTC 混音），设备侧仍半双工 PTT。一台设备同一时刻只属于一个任务房。点选单设备监看可自动建临时任务房以保持体验。本决策修订 ADR-0003/0004 中「严格一路」「不引入多路旁听」的表述；SecretKey 仍仅存后端。

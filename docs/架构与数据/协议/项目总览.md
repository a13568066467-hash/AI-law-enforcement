# 赢筑AI — 项目总览

> **text1** 仓库：DSJ-ZECN6A1 执法仪 App + 手机扫码 App + 云端 AI + MySQL 档案

---

## 1. 产品是什么

**赢筑AI** — 公司设备池内的执法仪主控 + 手机扫码绑定，面向工地/执法巡查。

| 端 | 功能 | 说明 |
|----|------|------|
| **执法仪** | 录像/拍照、AI、相册、扫码出码 | `android-app`，未绑定时「我的」展示 QR |
| **手机** | 登录/注册、扫执法仪码确认绑定 | `mobile-app` |
| **云端** | 绑定会话、档案、AI 代理 | `backend/` FastAPI + MySQL |

---

## 2. 技术路线

```
┌──────────────────────┐   HTTPS    ┌─────────────┐    API    ┌──────────┐
│ DSJ-ZECN6A1 + App    │ ◄────────► │  backend/   │ ◄───────► │ 百炼 AI  │
│ Camera2 / 按键 / UI  │            │ FastAPI+MySQL│           │ turbo/VL │
└──────────────────────┘            └─────────────┘           └──────────┘
         ▲                                    ▲
         │ 扫码绑定 confirm                   │ mobile/login|register
┌────────┴─────────────┐                     │
│ 手机 mobile-app      │ ────────────────────┘
└──────────────────────┘
```

---

## 3. 代码结构

```
text1/
├── android-app/     # 执法仪 Kotlin 主控 App
│   ├── platform/    # NativeRecorder、RecorderKeyDispatcher、ZE69
│   ├── data/        # SessionManager、ApiClient、BindBootMarker
│   └── ui/          # 五 Tab + 扫码绑定「我的」
├── mobile-app/      # 手机扫码绑定 App
│   └── ui/          # 登录、注册、扫码、确认绑定
├── backend/         # 云端 API + 设备绑定会话 + MySQL
└── docs/            # 产品/架构文档
```

**执法仪会话中心：** `SessionManager.kt` — 本机录像/拍照、绑定轮询、云端 API。

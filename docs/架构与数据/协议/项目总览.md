# 赢筑AI — 项目总览

> **text1** 仓库：DSJ-ZECN6A1 执法仪 App + 手机扫码 App + 云端 AI + Web 控制台  
> **权威词表：** [`CONTEXT.md`](../../CONTEXT.md) · **索引：** [`docs/README.md`](../README.md)

---

## 1. 产品是什么

**赢筑AI** — 公司设备池内的执法仪主控 + 手机扫码绑定，面向工地/执法巡查。

| 端 | 功能 | 说明 |
|----|------|------|
| **执法仪** | 录像/拍照、AI、相册、扫码出码、指挥连线共摄 | `android-app` |
| **手机** | 登录/注册、扫码确认绑定 | `mobile-app` |
| **云端** | 绑定、档案、AI、指挥连线会话/UserSig | `backend/` FastAPI + MySQL |
| **Web** | 监看/连线、现场事件工单 | `web-console` |

---

## 2. 技术路线

```
┌──────────────────────┐   HTTPS    ┌─────────────┐    API    ┌──────────┐
│ DSJ-ZECN6A1 + App    │ ◄────────► │  backend/   │ ◄───────► │ 百炼 AI  │
│ Camera2 / 按键 / UI  │            │ FastAPI+MySQL│           │ + TRTC   │
└──────────────────────┘            └─────────────┘           └──────────┘
         ▲                                    ▲
         │ 扫码绑定 confirm                   │ mobile / web
┌────────┴─────────────┐                     │
│ 手机 / Web 控制台    │ ────────────────────┘
└──────────────────────┘
```

媒体面：指挥连线 / 监看走 **腾讯云 TRTC**（后端签发凭证，不转发音视频）。

## 3. 代码结构

```
text1/
├── android-app/     # 执法仪 Kotlin 主控
├── mobile-app/      # 手机扫码绑定
├── web-console/     # 指挥监看 / 工单
├── backend/         # FastAPI；业务域见 docs/架构流程图
└── docs/            # 见 docs/README.md
```

**执法仪会话中心：** `SessionManager.kt` — 本机录像/拍照、绑定轮询、云端 API。

## 4. 开发顺序

| 阶段 | 目标 | 状态 |
|------|------|------|
| P0 | 本机 Camera2 + 按键 + 相册/录像页 | ✅ |
| P1 | 扫码绑定 + 手机 App + MySQL 档案 | ✅ |
| P2 | ASR/TTS / 全双工 Realtime（PTT 预热、推帧） | ✅ |
| P3 | 指挥连线 TRTC + 监看 + 占用持房 | ✅ |
| P4 | 系统签名、专机桌面、低功耗；GB28181 | 规划中 |

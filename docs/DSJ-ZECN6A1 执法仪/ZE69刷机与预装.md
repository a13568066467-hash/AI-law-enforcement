# ZE69 刷机、系统签名与默认桌面 — 操作手册

> **适用机型：** DSJ-ZECN6A1 · MTK **MT6768** · 项目 `k69v1_64_ZE69_ZY_3G` · 执法仪 user ROM  
> **厂商材料目录（勿入库）：** 桌面 `适配文档/`  
> **App 包名：** `com.aifieldcam.app` · 桌面 Activity：`MainActivity`

本手册与 [系统签名与适配.md](系统签名与适配.md)、[ZE69-驱动控制接口.txt](ZE69-驱动控制接口.txt) 配套，按 **ask-matt 主流程** 拆成可独立执行的 Phase。

---

## 总览（四 Phase）

| Phase | 目标 | 产出 | 建议会话 |
|-------|------|------|----------|
| **P0** | App 具备「桌面 + 系统签」能力 | HOME Manifest、platform 签 APK | 本仓库 `/implement` |
| **P1** | 原厂 ROM 上验证硬件 | 灯控/夜视/按键/摄录 OK | 真机 + adb |
| **P2** | 改刷机包预装 + 默认 Home | 新 `super.img` | WSL/ Linux + SP Flash Tool |
| **P3** | 量产与 OTA | 致业出厂或自维护 OTA | 厂商协同 |

**原则：** P0→P1 不通，不要改 super；P1 通后再做 P2。

## Phase P0 — App 与签名（仓库内）

### P0-1 构建未签名 release

```bat
cd android-app
gradlew.bat assembleRelease
```

产物：`app/build/outputs/apk/release/app-release-unsigned.apk`

### P0-2 platform 签名（适配文档内已有私钥）

```powershell
cd android-app\scripts
.\sign-platform.ps1 `
  -UnsignedApk "..\app\build\outputs\apk\release\app-release-unsigned.apk" `
  -OutApk "..\app\build\outputs\apk\release\AiFieldCam-platform.apk" `
  -KeyDir "C:\Users\任白\Desktop\适配文档"
```

需要本机有 **Java**；脚本会尝试 Android SDK 里的 `lib/apksigner.jar` 或同目录 `signapk.jar`。

### P0-3 Manifest 验收点

- `MainActivity` 含 `category.HOME` + `category.DEFAULT`
- `launchMode="singleTask"`
- 桌面按返回 → `moveTaskToBack`（不退出 App）

## Phase P1 — 刷原厂包 + 验功能（不改 system）

### P1-1 刷机

1. 解压 `k69v1_64_ZE69_ZY_3G.MT6768.emmc.user.zhifayi.0429-1613-12e6fa029ca.rar`
2. **SP Flash Tool** → 加载 `MT6768_Android_scatter.xml`
3. 模式选 **Download Only**（勿 Format All）
4. 关机，连 USB，刷入

### P1-2 安装 platform 签 APK

优先：**预装位**（P2）；P1 可临时：

```bat
adb install -r AiFieldCam-platform.apk
```

若安装失败（签名与 system 冲突），直接进 **P2 预装**。

### P1-3 设默认桌面（需 root / adb shell 权限）

```bash
# 先确认 ZECNClient 包名（见下「解包 ZECNClient」）
pm set-home-activity com.aifieldcam.app/.MainActivity
```

### P1-4 验收清单

| # | 项 | 通过标准 |
|---|-----|----------|
| 1 | 冷启动 | 进入赢筑 App 五 Tab |
| 2 | 录像 | Camera2 1080p，**rg_green** 亮 |
| 3 | 弱光 | 红外补光保持关闭 |
| 4 | 快门 | 识图 + TTS |
| 5 | 按键 | 录像/拍照/SOS 长按 |
| 6 | Home 键 | 回到本 App，不弹桌面选择 |

## Phase P2 — 改 super 预装（量产路径）

### P2-1 解 super（Linux/WSL 推荐）

```bash
sudo apt install android-sdk-libsparse-utils  # lpunpack 等，或下载 AOSP lpunpack
lpunpack super.img out/
# 得到 system.img system_ext.img product.img vendor.img ...
```

### P2-2 挂载并预装

```bash
mkdir sys_mount
sudo mount -o loop,rw system.img sys_mount

sudo mkdir -p sys_mount/system/priv-app/AiFieldCam
sudo cp AiFieldCam-platform.apk sys_mount/system/priv-app/AiFieldCam/AiFieldCam.apk

# 可选：priv-app 权限白名单
# sudo cp privapp-permissions-com.aifieldcam.app.xml sys_mount/system/etc/permissions/

sudo umount sys_mount
```

### P2-3 处理原厂桌面 ZECNClient

ROM 内预装 **`ZECNClient_preinstall.apk`**（`/system/app/ZECNClient_preinstall/`），通常即厂商主桌面。

**推荐（二选一）：**

| 方案 | 做法 | 风险 |
|------|------|------|
| **A 禁用组件** | 保留 APK，出厂脚本 `pm disable` HOME Activity | 低，可恢复 |
| **B 替换默认 Home** | overlay / `pm set-home-activity` 写进 `init` | 中 |
| **C 删除 ZECNClient** | 从 system 移除 | 高，可能丢 MDM/上传 |

**不要**在未确认依赖前删除 ZECNClient。

### P2-4 重打 super 并刷机

```bash
lpmake ...   # 按原分区大小重打包，或使用厂商脚本
# 替换刷机包内 super.img → SP Flash Tool 再刷
```

### P2-5 刷后首次开机

- 不应出现「选择桌面」
- 直接进入 `com.aifieldcam.app`
- 设置 → 设备信息 → sysfs 节点可写

## Phase P3 — 量产 / OTA（与致业协同）

- 由致业在 **同一 scatter 工程** 内加入 `priv-app/AiFieldCam` + default_home
- 保留 `MDMConfig`、`EmCamera` 等系统 App
- OTA 走 `FotaApp` 或厂商通道

---

## 解包 ZECNClient（P1 前必做）

在 `适配文档/apks/ZECNClient_preinstall.apk` 上：

```bat
# Android SDK build-tools
aapt dump badging ZECNClient_preinstall.apk | findstr package
aapt dump xmltree ZECNClient_preinstall.apk AndroidManifest.xml | findstr HOME
```

记录 **package** 与 **HOME activity**，写入 P1-3 / P2-3 命令。

## 刷机包文件索引

| 文件 | 说明 |
|------|------|
| `MT6768_Android_scatter.xml` | SP Flash 分区表 |
| `super.img` | system/product/vendor 动态分区 |
| `boot.img` / `vbmeta*.img` | 启动与 AVB |
| `preloader_*.bin` | 预引导 |
| `platform.pk8` / `platform.x509.pem` | **platform 签名（勿入库）** |
| `releasekey.pk8` / `releasekey.x509.pem` | release 签名 |
| `fw_apk_report.tsv` | 已解包系统 APK 列表 |

## 故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| sysfs 写失败 | 非 platform 签 / 非 priv-app | P0-2 + P2-2 |
| 刷机后不开机 | super 打包错误或 AVB | 恢复原厂 super |
| 仍进 ZECNClient | 未设 default Home | P1-3 或 P2-3 |
| 安装签包冲突 | 与 system 同包名不同签 | 只能预装，不要 adb 覆盖 system |

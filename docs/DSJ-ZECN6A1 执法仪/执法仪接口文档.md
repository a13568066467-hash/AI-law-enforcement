## 1. LED / 光感 / 红外（本机实有）

基路径：`/sys/devices/platform/odm/odm:camera_als/`  
（厂商原文里的 class leds、警示灯、蓝灯、`als_power` 当补光等本机不存在，已删；纠错见 [LED控制接口.md](LED控制接口.md)。）

| 设备名 | 操作节点 | 操作方式 |
|--------|----------|----------|
| 红色指示灯 | `…/camera_als/indicator_red_led` | 写 `1` 开 / `0` 关 |
| 绿色指示灯 | `…/camera_als/indicator_green_led` | 写 `1` 开 / `0` 关 |
| 白光 / 镭射灯 | `…/camera_als/radium_spotlight` | 写 `1` 开 / `0` 关 |
| 红外补光 | `…/camera_als/ir_led` | 写 `0` 关；`1`–`255` PWM 亮度 |
| 红外滤光片 | `…/camera_als/ir_door` | 写 `1` 开 / `0` 关 |
| 感光（只读） | `…/camera_als/als_data` | 数字字符串，可带换行，无单位 |

## 2. 静默安装 APK

广播：`com.kte.receiver.install_apk`

| Extra | 含义 |
|-------|------|
| `apk_file_path` | APK 绝对路径 |
| `start` | `false`＝装完不启动（默认） |

需带 `Intent.FLAG_RECEIVER_INCLUDE_BACKGROUND`（`0x01000000`）。

```java
Intent intent = new Intent("com.kte.receiver.install_apk");
intent.putExtra("apk_file_path", apkFilePath);
intent.putExtra("start", false);
intent.addFlags(0x01000000);
sendBroadcast(intent);
```

## 3. 暗码直接跳转

广播：`android.intent.action.SECRET_CODE`，包名限定 `com.android.settings`。

示例暗码：`*#*#3311#*#*`、`*#*#3322#*#*`、`*#*#6311#*#*`、`*#*#4636633#*#*`。

```java
Intent intent = new Intent("android.intent.action.SECRET_CODE")
    .setPackage("com.android.settings")
    .putExtra("SECRET_CODE", "*#*#3311#*#*");
sendBroadcast(intent);
```

ADB：

```bat
adb shell am broadcast -a android.intent.action.SECRET_CODE -e SECRET_CODE *#*#xxxx#*#* -p com.android.settings
```

## 5. UMS 共享 SD 卡

### 开关

| 方式 | 开启 | 关闭 |
|------|------|------|
| ADB | `am broadcast -a android.intent.action.ums -p com.android.settings --ez enable true` | 同上 `--ez enable false` |
| 代码 | `Intent("android.intent.action.ums").setPackage("com.android.settings").putExtra("enable", true\|false)` | |

### 是否已开启 UMS

监听 `android.hardware.usb.action.USB_STATE`，同时满足：

- `UsbManager.USB_CONFIGURED == true`
- `mass_storage == true`

### SD 是否已挂到 UMS

遍历 `StorageManager.getVolumes()`：类型为 `TYPE_PUBLIC`、可见，且 `state == 9` 时视为已共享。

## 8. OSD 水印（ImageReader / MediaRecorder）

系统集成 OSD：通过反射调用 `setImageOsd(instance, osdTextPos, osdText)`。

| 参数 | 说明 |
|------|------|
| `osdTextPos` | 多项用 `;` 分隔；每项 `x,y,transform,fontSize` |
| `x` / `y` | 相对图坐标，范围 0–1 |
| `transform` | 0 默认；1 水平镜像；2 垂直镜像；3 转 180°；4 转 90°；5＝1+4；6＝2+4；7 转 270° |
| `fontSize` | 12–100 |
| `osdText` | 多段水印文本，`;` 分隔，与 pos 一一对应 |

`MediaRecorder` 版接口参数相同，仅第一个参数改为 `MediaRecorder` 实例。

## 10. 系统管控杂项（ADB / settings）

| 能力 | 命令 / 说明 |
|------|-------------|
| 切换桌面 | `adb shell am broadcast -a android.intent.action.set_home -p com.android.settings -e default_home $packagename` |
| 采集站模式开 | `adb shell settings put global FEATURE_DATA_ONLY_MODE 1` |
| 采集站模式关 | `adb shell settings put global FEATURE_DATA_ONLY_MODE 0` |
| 安装黑名单 | `settings put global apk_install_restrict_rule "0,aaa,bbb"`（禁止安装列出包名） |
| 安装白名单 | `settings put global apk_install_restrict_rule "1,aaa,bbb"`（仅允许列出包名） |
| 禁止一切安装 | `settings put global apk_install_restrict_rule 1`（仅 `1`、无包名） |
| 解除安装限制 | `settings delete global apk_install_restrict_rule` |
| 隐藏导航栏 | `settings put global hide_nav_bar 1` |
| 显示导航栏 | `settings put global hide_nav_bar 0` |
| 设置系统时间 | 广播 `com.kingtop.setdt`，参数为毫秒 `long`：`adb shell am broadcast -a com.kingtop.setdt -p com.android.settings --el …` |

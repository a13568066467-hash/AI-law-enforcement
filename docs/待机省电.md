# 待机续航（Standby Power）

> 固件模块：`standby_mgr.c` · 与 `power_mgr.c`（电量 ADC）分工不同

## 分工

| 模块 | 职责 |
|------|------|
| **power_mgr** | ADC 分压 → 百分比；≤15% 提醒；≤10% 禁开录/AI |
| **standby_mgr** | **AI 聆听空闲**自动关麦；**IDLE 长时间无操作**轻睡眠；IMU 静置（待接 BMI270） |

## 功耗档位（策略）

| 档位 | FSM 状态 | 行为 | 目的 |
|------|----------|------|------|
| **ACTIVE** | RECORD / CAPTURE | 不睡眠 | 录像/拍照 |
| **AI_LISTEN** | AI_ASSIST | 无活动 ≥ **5s**（默认）→ 自动 `stop_ai` → IDLE | **AI 待机续航**：避免一直开麦耗电 |
| **IDLE_WAIT** | IDLE 已开机 | 计时，未到空闲阈值 | 胸挂待命 |
| **LIGHT_SLEEP** | IDLE + 超时 | `esp_light_sleep`，GPIO1/2/3 唤醒 | 待机 12h+ 目标 |

与 [项目总览.md](./项目总览.md) §6.3 一致：**VAD 静音约 5s → STOP_AI → IDLE**。

## 默认配置（menuconfig）

| 配置项 | 默认 | 含义 |
|--------|------|------|
| `STANDBY_MGR_ENABLE` | y | 总开关 |
| `STANDBY_AI_LISTEN_IDLE_SEC` | 5 | AI 聆听无活动自动退出 |
| `STANDBY_IDLE_TIMEOUT_SEC` | 300 | IDLE 5 分钟后可进轻睡眠 |
| `STANDBY_LIGHT_SLEEP_ENABLE` | **n** | 轻睡眠（调试可先关，接线稳定后开） |
| `STANDBY_POLL_MS` | 1000 | 策略轮询周期 |
| `STANDBY_IMU_ENABLE` | n | 需 IMU 静置才睡（驱动 TODO） |

## 活动刷新（重置计时）

以下会调用 `standby_mgr_notify_activity()`：

- 任意按键有效边沿（`button.c`）
- FSM 状态切换（`enter_state`）
- 轻睡眠唤醒后

后续 BLE 写命令、IMU 运动检测也应调用同一接口。

## 串口示例

**AI 自动退出：**

```
I (standby) AI listen idle 5 s — auto stop (save power)
I (fsm) AI listen idle timeout — back to idle (standby)
```

**轻睡眠（需开启 `STANDBY_LIGHT_SLEEP_ENABLE`）：**

```
I (standby) light sleep enter (idle 300 s)
I (standby) light sleep wake (GPIO)
```

## 续航预期（参考 PRD）

| 场景 | 2000mAh 量级（粗估，待实测） |
|------|------------------------------|
| 开机 IDLE + 轻睡眠 | 待机 **12h+** 目标 |
| AI 对话连续 | **2–3h**（麦 + BLE + App 网关） |
| 仅偶发 AI（5s 自动关） | 显著长于连续对话 |

## IMU（V1 占位）

- `STANDBY_IMU_ENABLE=n`：仅按**时间**判断空闲。
- 开启后需接 BMI270（GPIO21/9，可选），`standby_mgr.c` 内 TODO 读加速度；平放/无运动才允许轻睡眠。

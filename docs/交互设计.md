# 交互设计 — AI 实地相机

> 形态：胸牌夹相机（无屏）· 详见 [外观形态.md](./外观形态.md)

## 机身顶面布局

```
┌─────────────────────────────────────┐
│  顶面（面向使用者时）                 │
│                                     │
│  [ AI键 ]   [ 快门键 ]   [ 电源键 ]  │
│   双击唤醒    单击拍照      长按开关机  │
│              长按1s录像*             │
└─────────────────────────────────────┘
* 长按快门录像为 V1.1 可选
```

## 操作表

| 操作 | 行为 | 反馈 |
|------|------|------|
| 长按电源 3s（关机） | 开机 | 蓝闪 + 「已开机」 |
| 长按电源 3s（开机） | 关机 | 「已关机」 |
| 单击快门 | 拍照 → 自动识别 | 快门音 + 白灯闪 |
| 双击 AI 键 | 唤醒 AI 助手 | 「我在」+ 蓝灯常亮 |
| 语音「开始录像」 | 开始录像 | 红灯常亮 |
| 语音「停止录像」 | 停止并保存 | 「录像已保存」 |
| 静置超时 / 平放检测* | 停录、关麦 | 进入低功耗 |
| 取下胸挂静置* | 同上 | 可选策略 |

\* IMU 静置策略可在 App 设置中开关

## LED 状态（正面）

| 状态 | LED |
|------|-----|
| 已连接 | 蓝灯慢闪 |
| AI 聆听 | 蓝灯常亮 |
| 录像中 | 红灯常亮 |
| 拍照 | 白灯闪 |
| 低电 | 红灯快闪 |

## 实地语音指令示例

```
开始录像 / 停止录像
识别一下 / 拍一张
读一下这个铭牌 / 这是什么材料
记录一下：今天三层验收通过
停止 / 再见
```

## 挂载与操作提示

| 挂载 | 操作建议 |
|------|----------|
| 胸挂 | 默认模式；快门对准目标，AI 键双击免提 |
| 头戴 | 真 POV 录像；识别时短暂停步对准 |
| 三脚架 | 定点录像；可走远后用 App 查看 |

## 冲突处理

1. 录像中双击 AI 键 → 提示「请先停止录像」或自动停录
2. AI 播放 TTS 时单击快门 → 打断 TTS，执行拍照
3. 低电 ≤15% 喇叭提醒；≤10% 禁用录像和 AI，仅保留拍照和关机
4. 现场噪声过大 → App 可调高降噪等级；提示靠近机身或稍停步

## 1. 产品定位

### 1.1 一句话

**DSJ-ZECN6A1 赢筑AI** — 本机 Android 主控；Camera2 录像/拍照、云端识图与对话、物理按键；巡查员联网认证；智能在 **公司云端**。

### 1.2 目标分层（宣传 / 工程对齐）

| 层级 | 来源 | 目标 |
|------|------|------|
| L0 对外 | 赢筑宣传 PPT / 场景要点 | 智慧工地九大场景 + 端平台闭环 |
| L1 终态 | [项目总览.md](../architecture/项目总览.md) §4 | 系统级 App、GB28181、WebRTC、全双工 PTT |
| **L2 MVP** | **本文** | 本机摄录 + 识图/对话 + 巡查员 + 场景演示 |
| L3 当前 | 代码 | Camera2、按键、ZE69 灯控（需系统签名）、Demo 场景 |

### 1.3 与市面执法记录仪的差异

| 维度 | 典型执法机 | 本产品 |
|------|-----------|--------|
| 核心卖点 | 录像回传、GPS 证据链、VMS 平台 | **AI 识图解说 + 助手 + 工地场景** |
| 联网 | 4G + 监管平台 | **本机 4G/Wi‑Fi → 公司后端**（GB28181 规划中） |
| 智能 | 平台侧录像管理为主 | **多模态 VLM 识图 + Agent A/B 对话** |
| 用户配置 | 常需平台账号/APN | **扫码绑定 + 手机建档，无 API Key 页** |

### 1.4 V1 明确排除

- 眼镜 / AR 形态  
- **组呼对讲 PTT**（与 ASR「按住说话」不同，V2 再议）  
- 机身红外测温、二维码专用扫码头  
- 录像中实时识物、端侧大模型  
- GB28181 / 管控平台 / 工单闭环（L1，非 MVP）

| 用户 | 典型场景 | 最常用功能 |
|------|----------|------------|

## 3. 核心功能（优先级）

> **对外顺序：** ① 拍照识图 ② AI 助手 ③ 录像留痕

### 3.1 拍照与 AI 识图（P0）

| 项目 | 规格 |
|------|------|
| 相机 | 本机 Camera2，JPEG |
| 云端模型 | `qwen3-vl-8b-instruct`（见 [云端AI代理.md](../guides/云端AI代理.md)） |
| 默认 | 快门键 → 拍照 → `POST /v1/vision` → 展示/播报 |
| 追问 | 会话内 Agent B + `last_explanation` |

**验收：** 拍完 3–8s 内有说明；追问 3 轮不编造。

### 3.2 AI 助手（P0）

| 项目 | 规格 |
|------|------|
| 输入 | AI 页文字（V1）；ASR/TTS 为 P2 |
| 模型 | Agent A/B，`qwen-turbo` |
| 控制 | 意图 → `ble_cmds`（兼容字段名）→ **SessionManager 本机执行** |

| 能力 | 示例 |
|------|------|
| 控录像 | 「开始录像」「停止录像」 |
| 控识图 | 「识别一下」 |
| 追问 | 「刚才那个型号是什么」 |
| 现场记录 | 「记录一下：…」 |

**验收：** 文字开/停录像 3s 内响应；登录后可对话。

### 3.3 录像留痕（P0）

| 项目 | 规格 |
|------|------|
| 分辨率 | 1080p @ 30fps，H.264 MP4 |
| 存储 | 本机 + 相册 |
| 触发 | **录像键** / App / 语音意图 |
| 指示 | ZE69 **rg_green**（需 [系统签名](../hardware/系统签名与适配.md)） |

**验收：** 连续 5 min 不崩；停止后 30s 内可播放。

### 3.4 硬件适配（P0 · 本机）

| 项目 | 规格 |
|------|------|
| 平台 | ZE69 sysfs（[驱动接口](../hardware/ZE69-驱动控制接口.txt)） |
| 夜视 | 红外补光禁用；`NightVisionController` 不启用 ALS 自动红外 |
| 按键 | `RecorderKeyDispatcher`：录像 / 快门 / SOS 长按 |
| 签名 | 系统签名后状态灯才生效；红外补光保持关闭 |

## 6. 系统架构

```
DSJ 执法仪（Camera2 / 按键 / ZE69 sysfs）
    ↔ 主控 App（SessionManager + HTTPS）
    ↔ 公司云端（AI / 巡查员 MySQL）
```

| 约束 | 说明 |
|------|------|
| 密钥仅在后端 | App 不持百炼 Key |
| 巡查员认证 | 扫码绑定须联网；人员档案由手机/后台维护 |
| 本机主路径 | 不依赖外接 BLE / 胸牌相机 |

## 7. 辅助能力

| 能力 | 规格 |
|------|------|
| 按键 | 录像键、快门键、SOS 长按（见 [交互设计.md](交互设计.md)） |
| LED | 三色灯 + 红绿灯，映射见 ZE69 文档 |
| 低电 | ≤15% **rgb_red** 警示；≤10% 禁新录像/AI（`BatteryPolicy`） |
| TTS | 识图说明与 AI 回复本机播报（`TtsSpeaker`） |
| 续航 | 规格单电 1080p 约 18h（硬件）；App 连续对话待实测 |

## 10. 验收总表

```
登录 → 快门识图 → AI「开始录像」→ 停止 → 回放
     → 追问「刚才那个参数」
```

| # | 项 | 标准 |
|---|-----|------|
| 1 | 本机录像 | Camera2 开始/停止 |
| 2 | 识图 | 8s 内有说明 |
| 3 | 控录 | 文字 3s 内响应 |
| 4 | 扫码绑定 | 执法仪出码 + 手机确认 → 摘要显示 |
| 5 | ZE69（签后包） | 录像绿灯、弱光夜视 |

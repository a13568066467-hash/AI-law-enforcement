## 1. 产品定位

### 1.1 一句话

**DSJ-ZECN6A1 智能执法记录仪** — 本机 Android 主控；拍照识图、AI 助手、Camera2 录像；巡查员联网认证；智能在 **公司云端**。

### 1.2 与市面执法记录仪的差异

| 维度 | 典型执法机 | 本产品 |
|------|-----------|--------|
| 核心卖点 | 录像回传、GPS 证据链、VMS 平台 | **AI 识图解说 + 语音助手 + 工地场景** |
| 联网 | 4G + 监管平台 | **本机 4G/Wi‑Fi → 公司后端**（GB28181 规划中） |
| 智能 | 平台侧录像管理为主 | **多模态 VLM 识图 + Agent A/B 对话** |
| 用户配置 | 常需平台账号/APN | **工人登录 App 即可，无 API Key 页** |

### 1.3 不做（V1 明确排除）

- 眼镜 / AR 眼镜形态  
- 机身内置 4G/5G 模组（见 V2 路线图）  
- 机身大屏 Android、组呼 PTT、红外测温  
- 录像中实时识物、端侧大模型、二维码专用扫码头

## 2. 目标用户与场景

| 用户 | 典型场景 | 最常用功能 |
|------|----------|------------|
| 现场工程师 | 巡检、施工面记录 | 识图 + 语音追问 |
| 质检/验收 | 铭牌、仪表、标签读数 | 快门识图 + 播报 |
| 项目经理 | 远程掌握现场、留痕 | 录像 + 相册归档 |
| 项目部 IT/管理 | 额度、日志、项目绑定 | 后台（P6） |

| 场景 | 操作示例 |
|------|----------|
| 设备铭牌识读 | 胸挂对准 → 单击快门 → 听型号参数 |
| 材料/工具识别 | 「识别一下」或快门 |
| 巡检留痕 | 「开始录像」→ 走动记录 → 「停止录像」 |
| 问题记录 | 双击 AI → 「记录一下：三层钢筋间距偏大」 |
| 追问上一张 | 「刚才那个额定电压是多少？」 |

## 3. 核心功能（优先级排序）

> **对外顺序：** ① 拍照识图 ② AI 语音助手 ③ 录像留痕

### 3.1 拍照与 AI 识图解释（P0 · 最强差异）

| 项目 | 规格 |
|------|------|
| 相机 | 本机 Camera2，JPEG/MP4 |
| 云端模型 | `qwen3-vl-8b-instruct`（见 [云端AI代理.md](../guides/云端AI代理.md)） |
| 默认行为 | 单击快门 → 拍照 → 识图 → TTS 播报 |
| 追问 | 会话内基于 `last_explanation`（Agent B） |
| 传输 | 本机采集 → App → `POST /v1/vision` |

| 模式 | 触发 | 行为 |
|------|------|------|
| 拍照 + 解释 | 单击快门（默认） | 识图 + 播报 |
| 仅拍照 | 可配置关闭自动识图 | 只进相册 |
| 语音识图 | 「识别一下」「拍一张」 | CMD 拍照 + vision |

**验收：**

- 拍完 **3–8s** 内开始播报（视网络）  
- 铭牌/仪表/现场物体 **各 5 例** 可用  
- 追问 **3 轮** 不编造（无依据时提示再拍）  

**V1 不做：** 二维码/条码专用引擎、录像中实时识物。

### 3.2 AI 语音助手（P0）

| 项目 | 规格 |
|------|------|
| 唤醒 | 双击 **AI 键**；串口/播报「我在」 |
| 对话模型 | Agent A/B，`qwen-turbo` |
| 拾音 | 双 INMP441 + 云端 ASR（P2 Opus 上行） |
| 控制 | 意图 → `ble_cmds` → 设备执行 |

| 能力 | 语音示例 |
|------|----------|
| 控录像 | 「开始录像」「停止录像」 |
| 控识图 | 「识别一下」「再拍一张」 |
| 追问识图 | 「刚才那个型号是什么」 |
| 现场记录 | 「记录一下：…」 |
| 短答闲聊 | 规范、提醒（Agent A 限长） |

**验收：**

- 双击 AI **1s 内**「我在」  
- 语音开/停录像 **3s 内** 响应  
- 胸挂正常工地噪声下可对话（双麦降噪）  

### 3.3 录像留痕（P0）

| 项目 | 规格 |
|------|------|
| 分辨率 | 1080p @ 30fps |
| 格式 | H.264 MP4 |
| 存储 | 本机 filesDir + 系统相册 |
| 触发 | 物理录像键 / App 按钮 / 语音「开始/停止录像」 |
| 互斥 | 录像中禁止开 AI；AI 中禁止开录像 |

**验收：**

- 720p 连续 **5 min** 不崩  
- 停止后 **30s 内** App 可播放  
- 胸挂行走场景可用

## 4. 证据与归档（P1 · 对标平台「留痕」）

V1 不拼机身 GPS/4G，用 **账号 + 手机侧元数据** 形成最小证据链：

| 字段 | 来源 | 用途 |
|------|------|------|
| `worker_id` / 登录 token | App 登录 | 谁操作 |
| `project_id` | 后台绑定（P6） | 哪个项目 |
| `device_id` | BLE 连接 | 哪台机身 |
| `session_id` | App 会话 | 一次上工会话 |
| `captured_at` | 手机时间 | 何时 |
| `geo`（可选） | **手机 GPS** | 何地（V1.1 默认开） |
| `vision_text` | `/v1/vision` | AI 识图说明 |
| `chat_log` | `/v1/chat` | 对话与指令记录 |

**验收：** 相册每条记录可展示「时间 + 识图摘要」；后台可导出巡检记录（P6）。

## 6. 系统架构（需求约束）

```
DSJ 执法仪（Camera2 / 按键 / 4G）  ←→  主控 App  ←→  公司云端（AI/鉴权/MySQL）
```

| 约束 | 说明 |
|------|------|
| 机身不直连百炼 | 密钥仅在后端 |
| 巡查员联网认证 | 注册/登录/注销必须联网 |
| 本机主路径 | 不再依赖外接 BLE 胸牌相机 |

## 7. 辅助能力

| 能力 | 规格 |
|------|------|
| 降噪 | 双麦立体声 + 云端 ASR；V1 对话页可先文字 |
| 续航 | 2000mAh；待机 12h+；连续对话 2–3h；录像累计 45–90 min/充 |
| 按键 | 电源长按 3s；快门单击；AI 双击 |
| 低电 | ≤15% 提醒；≤10% 禁新录像/AI；**充电中可边充边用** |
| 待机 | AI 5s 无活动关麦；空闲轻睡眠（[待机省电.md](../hardware/待机省电.md)） |
| LED | 蓝=连接/AI；红=录像；白闪=拍照；红闪=低电 |

## 8. MVP 与版本边界

### 8.1 V1 必须交付（MVP）

- [ ] DSJ 本机 App 五 Tab
- [ ] Camera2 录像 + 本机拍照
- [ ] `/v1/vision` 识图
- [ ] `/v1/chat` 文字控录像、识图
- [ ] Agent B 追问上一张
- [ ] 巡查员注册 + 人脸登录

### 8.2 V1.1

- 长按快门一键录像  
- 手机 GPS 写入相册元数据  
- Opus 麦上行 + 云端 ASR（替代打字）  
- TTS → 机身喇叭（`AUDIO_RX`）  
- 帽夹套件、IP54 外壳、防风套  

### 8.3 V2（预留，不投入 V1）

- 机身 WiFi 快传 / 可选 4G 棒  
- 设备证书直连公司 API（工人仍零配置）  
- 采集座批量充电导出  
- 端侧 YOLO 与 VL 混合（二选一策略）

## 10. 验收总表（MVP 工人路径）

```
登录 App → 本机拍照识图 → 文字「开始录像」→ 停止 → 录像页回放
         → AI 对话 → 追问「刚才那个参数」
```

| # | 项 | 标准 |
|---|-----|------|
| 1 | 本机录像 | Camera2 开始/停止正常 |
| 2 | 识图 | 拍照后 8s 内有说明 |
| 3 | 控录 | 文字开录 3s 内响应 |
| 4 | 认证 | 注册 + 人脸登录 |

## 1. 产品定位

### 1.1 一句话

**项目现场 AI 胸牌相机** — 胸挂佩戴、无屏轻量；拍完能用 **口语解释现场**，能 **语音控录像**，工人 **只连手机、零配网**，智能在 **公司云端**（非机身 4G 执法仪路线）。

### 1.2 与市面执法/胸牌记录仪的差异

对标行业胸牌/执法记录仪（如 [BesoVideo 胸牌/执法仪系列](https://www.besovideo.com/en/product?cId=2)）时，**不正面竞争**「机身 4G/5G + 大屏 + 纯录像取证平台」：

| 维度 | 典型执法/胸牌机 | 本产品 V1 |
|------|-----------------|-----------|
| 核心卖点 | 录像回传、GPS 证据链、VMS 平台 | **AI 识图解说 + 语音助手 + 追问** |
| 联网 | 机身 4G/5G/WiFi 直云 | **BLE → 手机 App → 公司后端** |
| 智能 | 平台侧录像管理为主 | **多模态 VLM 识图 + Agent A/B 对话** |
| 用户配置 | 常需平台账号/APN | **工人登录 App 即可，无 API Key 页** |

### 1.3 不做（V1 明确排除）

- 眼镜 / AR 眼镜形态  
- 机身内置 4G/5G 模组（见 V2 路线图）  
- 机身大屏 Android、组呼 PTT、红外测温  
- 录像中实时识物、端侧大模型、二维码专用扫码头

## 2. 目标用户与场景

| 用户 | 典型场景 | 最常用功能 |
|------|----------|------------|
| 现场工程师 | 巡检、施工面记录 | 识图 + 语音追问 |
| 质检/验收 | 铭牌、仪表、标签读数 | 快门识图 + 播报 |
| 项目经理 | 远程掌握现场、留痕 | 录像 + 相册归档 |
| 项目部 IT/管理 | 额度、日志、项目绑定 | 后台（P6） |

| 场景 | 操作示例 |
|------|----------|
| 设备铭牌识读 | 胸挂对准 → 单击快门 → 听型号参数 |
| 材料/工具识别 | 「识别一下」或快门 |
| 巡检留痕 | 「开始录像」→ 走动记录 → 「停止录像」 |
| 问题记录 | 双击 AI → 「记录一下：三层钢筋间距偏大」 |
| 追问上一张 | 「刚才那个额定电压是多少？」 |

## 3. 核心功能（优先级排序）

> **对外顺序：** ① 拍照识图 ② AI 语音助手 ③ 录像留痕

### 3.1 拍照与 AI 识图解释（P0 · 最强差异）

| 项目 | 规格 |
|------|------|
| 相机 | OV5640，JPEG |
| 云端模型 | `qwen3-vl-8b-instruct`（见 [云端AI代理.md](./云端AI代理.md)） |
| 默认行为 | 单击快门 → 拍照 → 识图 → TTS 播报 |
| 追问 | 会话内基于 `last_explanation`（Agent B） |
| 传输 | 设备 BLE 分片 → App → `POST /v1/vision` |

| 模式 | 触发 | 行为 |
|------|------|------|
| 拍照 + 解释 | 单击快门（默认） | 识图 + 播报 |
| 仅拍照 | 可配置关闭自动识图 | 只进相册 |
| 语音识图 | 「识别一下」「拍一张」 | CMD 拍照 + vision |

**验收：**

- 拍完 **3–8s** 内开始播报（视网络）  
- 铭牌/仪表/现场物体 **各 5 例** 可用  
- 追问 **3 轮** 不编造（无依据时提示再拍）  

**V1 不做：** 二维码/条码专用引擎、录像中实时识物。

### 3.2 AI 语音助手（P0）

| 项目 | 规格 |
|------|------|
| 唤醒 | 双击 **AI 键**；串口/播报「我在」 |
| 对话模型 | Agent A/B，`qwen-turbo` |
| 拾音 | 双 INMP441 + 云端 ASR（P2 Opus 上行） |
| 控制 | 意图 → `ble_cmds` → 设备执行 |

| 能力 | 语音示例 |
|------|----------|
| 控录像 | 「开始录像」「停止录像」 |
| 控识图 | 「识别一下」「再拍一张」 |
| 追问识图 | 「刚才那个型号是什么」 |
| 现场记录 | 「记录一下：…」 |
| 短答闲聊 | 规范、提醒（Agent A 限长） |

**验收：**

- 双击 AI **1s 内**「我在」  
- 语音开/停录像 **3s 内** 响应  
- 胸挂正常工地噪声下可对话（双麦降噪）  

### 3.3 录像留痕（P0）

| 项目 | 规格 |
|------|------|
| 分辨率 | 720p @ 15fps |
| 格式 | MJPEG |
| 单次时长 | 默认 5 min（可配置 10 min） |
| 存储/传输 | V1：**BLE VIDEO_TX → App**（机身不插 SD，与双麦冲突） |
| 触发 | 语音「开始/停止录像」；V1.1 长按快门 1s |
| 互斥 | 录像中禁止开 AI；AI 中禁止开录像 |

**验收：**

- 720p 连续 **5 min** 不崩  
- 停止后 **30s 内** App 可播放  
- 胸挂行走场景可用

## 4. 证据与归档（P1 · 对标平台「留痕」）

V1 不拼机身 GPS/4G，用 **账号 + 手机侧元数据** 形成最小证据链：

| 字段 | 来源 | 用途 |
|------|------|------|
| `worker_id` / 登录 token | App 登录 | 谁操作 |
| `project_id` | 后台绑定（P6） | 哪个项目 |
| `device_id` | BLE 连接 | 哪台机身 |
| `session_id` | App 会话 | 一次上工会话 |
| `captured_at` | 手机时间 | 何时 |
| `geo`（可选） | **手机 GPS** | 何地（V1.1 默认开） |
| `vision_text` | `/v1/vision` | AI 识图说明 |
| `chat_log` | `/v1/chat` | 对话与指令记录 |

**验收：** 相册每条记录可展示「时间 + 识图摘要」；后台可导出巡检记录（P6）。

## 5. 外观与挂载（P0）

| 项目 | V1 规格 |
|------|---------|
| **默认形态** | **胸牌夹相机**（无屏），非消费级方块 |
| 目标尺寸 | 约 **48 × 38 × 18 mm**（胸牌方向，可略厚） |
| 目标重量 | **≤ 55 g**（含 2000mAh） |
| 默认挂载 | **胸挂夹**（织带 + 快拆） |
| 可选挂载 | 帽夹、肩夹磁吸、1/4 三脚架 |
| 防护 | 镜头保护圈、进音防尘网；V1.1 目标 IP54 |

详见 [外观形态.md](./外观形态.md)。

## 6. 系统架构（需求约束）

```
XIAO 机身（采集/播放/BLE）  ←→  手机 App（网关/UI）  ←→  公司云端（AI/鉴权）
```

| 约束 | 说明 |
|------|------|
| 机身不直连百炼 | 密钥仅在后端 |
| 工人零配置 | 无 API Key 设置；内置 API 域名 + 登录 |
| 手机必带 | V1 依赖 BLE；无手机则无 AI（可本地快门缓存） |

硬件：[XIAO硬件接线.md](./XIAO硬件接线.md) · 软件：[App开发指南.md](./App开发指南.md)

## 7. 辅助能力

| 能力 | 规格 |
|------|------|
| 降噪 | 双麦立体声 + 云端 ASR；V1 对话页可先文字 |
| 续航 | 2000mAh；待机 12h+；连续对话 2–3h；录像累计 45–90 min/充 |
| 按键 | 电源长按 3s；快门单击；AI 双击 |
| 低电 | ≤15% 提醒；≤10% 禁新录像/AI；**充电中可边充边用** |
| 待机 | AI 5s 无活动关麦；空闲轻睡眠（[待机省电.md](./待机省电.md)） |
| LED | 蓝=连接/AI；红=录像；白闪=拍照；红闪=低电 |

## 8. MVP 与版本边界

### 8.1 V1 必须交付（MVP）

- [ ] 胸挂原型机 + App 五页  
- [ ] BLE 连接 + **一张真 JPEG** 进相册  
- [ ] `/v1/vision` 识图播报（或 mock）  
- [ ] `/v1/chat` 语音/文字控录像、识图  
- [ ] Agent B 追问上一张  
- [ ] 720p 录像 BLE 传 App 回放  
- [ ] 证据字段：时间 + session + 识图摘要  

### 8.2 V1.1

- 长按快门一键录像  
- 手机 GPS 写入相册元数据  
- Opus 麦上行 + 云端 ASR（替代打字）  
- TTS → 机身喇叭（`AUDIO_RX`）  
- 帽夹套件、IP54 外壳、防风套  

### 8.3 V2（预留，不投入 V1）

- 机身 WiFi 快传 / 可选 4G 棒  
- 设备证书直连公司 API（工人仍零配置）  
- 采集座批量充电导出  
- 端侧 YOLO 与 VL 混合（二选一策略）

## 10. 验收总表（MVP 工人路径）

```
登录 App → 连蓝牙 → 单击快门识图播报 → 语音「开始录像」→ 停止 → 相册回放
         → 双击 AI 对话 → 追问「刚才那个参数」→ 听答复
```

| # | 项 | 标准 |
|---|-----|------|
| 1 | 连接 | 30s 内连上 `AI-FieldCam` |
| 2 | 识图 | 快门后 8s 内有播报/文字 |
| 3 | 控录 | 语音开录 3s 内红灯 |
| 4 | 录像 | 5 min 不崩，App 可播 |
| 5 | AI | 双击 1s 内「我在」 |
| 6 | 低电 | ≤10% 禁录有提醒音 |

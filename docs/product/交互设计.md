## 1. 机身按键

> 厂商《按键操作说明》+ ROM `mtk-kpd.kl`。详见 [按键映射.md](../hardware/按键映射.md)。

| 按键 | 操作 | 行为 | 状态灯 |
|------|------|------|--------|
| 录音键 F2 | 短按 | 开/停 **音频** 录音 | 黄灯闪 |
| 录像键 F5 | 短按 | 开/停 **视频** 录像 | 红灯闪 |
| 拍照键 F4 | 短按 | 拍照 | 红灯闪一次 |
| PTT F6 | 短按 | 白光灯 | — |
| PTT F6 | 长按 | 对讲演示 | 蓝灯（辅助） |
| SOS F3 | 短按 | 重点标记 | — |
| SOS F3 | 长按 | 应急演示 | — |
| 开关键 | 长按/短按 | 开关机 / 亮灭屏 | 系统 |

**红外：不自动开启**（见 [按键映射.md](../hardware/按键映射.md) §3）。

## 2. LED / 灯控（ZE69 sysfs）

| 业务状态 | 说明书 | sysfs / 实现 |
|----------|--------|--------------|
| 待机 | 绿灯常亮 | `rg_green` · `DeviceStatusIndicator` |
| 录音 | 黄灯闪 | `rg_red`+`rg_green` 同闪 |
| 录像 | 红灯闪 | `rg_red` 闪烁 |
| 拍照 | 红灯闪一次 | `pulsePhotoCapture()` |
| 充电 / 充满 | 红常亮 / 绿常亮 | 电池广播 |
| PTT 对讲 | （说明书未规定） | `rgb_blue` 辅助 |
| 白光灯 | PTT 短按 | `rgb` 三色全亮近似 |
| 红外夜视 | **禁用** | 已禁用 ALS 自动；App 强制 `ir_led`+`ir_door` 关闭 |

Debug 包无法写入 sysfs 时，App 功能仍可用，仅机身灯不亮。

## 5. 冲突处理

> **录像 F5 / 拍照 F4 为全局行为**：亮屏 Activity、息屏无障碍侧键、首页按钮均经 `SessionManager` + `MediaInteractionPolicy` 同一套互斥规则。

1. 录像中拍照 → 提示先停止录像  
2. 录像启动中（preparing）→ 禁止拍照；可按 F5 取消启动  
3. 拍照进行中 → 禁止开录；连按 F4 提示「正在拍照」  
4. 录音中 → 禁止录像与拍照（麦克风/相机争用）  
5. 未登录 → 识图仅本地预览  
6. 低电 → `BatteryPolicy`：≤15% 红灯 + 提示；≤10% 禁新录像/拍照/AI  
7. 录像 ↔ AI → `SessionPolicy`：录像中仅允许「停止录像」类指令；AI 忙时不可开录  
8. 亮屏且 App 前台 → Activity 接管侧键；无障碍不重复消费（`RecorderKeyRoute`）  
9. 夜视 → **不自动开启红外**；`NightVisionController` 已禁用 ALS 自动

### Android 12（API 31）合规要点

设备 DSJ-ZECN6A1 运行 Android 12，需满足 [Android 12 后台限制](https://developer.android.google.cn/about/versions/12/get?hl=zh-cn)：

| 要求 | 实现 |
|------|------|
| 后台使用相机/麦克风 | `RecordingForegroundService` 声明 `foregroundServiceType=camera\|microphone` |
| 息屏侧键 | 无障碍「执法仪侧键」+ `RecorderKeyRoute` |
| 相册写入 | `MediaStore` + `IS_PENDING`（无需 `WRITE_EXTERNAL_STORAGE` on API 29+） |
| 停录失败清理 | `abortNativeRecordingSession` 释放 FGS 与 UI 占位 |

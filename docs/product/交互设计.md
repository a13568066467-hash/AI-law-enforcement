## 1. 机身按键

| 按键 | 行为 | 反馈 |
|------|------|------|
| 录像键（F9 等） | 开始/停止 Camera2 录像 | **rg_green** 常亮（需系统签名） |
| 快门键（CAMERA 等） | 拍照 → 自动识图 | 相册更新 + **rgb 绿闪** + TTS 播报 |
| SOS 键长按 | 应急演示场景 | 弹窗 + 云端 demo |

映射代码：`RecorderKeyDispatcher` → `SessionManager`。

## 2. LED / 灯控（ZE69 sysfs）

| 灯组 | sysfs | 业务用途 |
|------|-------|----------|
| 三色 · 红 | `rgb_red_led` | 低电量警示 |
| 三色 · 绿 | `rgb_green_led` | 预留 |
| 三色 · 蓝 | `rgb_blue_led` | AI 聆听 |
| 红绿 · 红 | `rg_red_led` | 与录像绿互斥 |
| 红绿 · 绿 | `rg_green_led` | **录像中** |
| 镭射 | `leise_led` | 预留 / 瞄准指示 |
| 红外 | `ir_led` (0–255) | 夜视补光 |
| IR_CUT | `ir_door` | 夜视滤光切换 |
| 光感 | `als_data`（只读） | 自动夜视阈值 |

Debug 包无法写入 sysfs 时，App 功能仍可用，仅机身灯不亮。见 [系统签名与适配.md](../hardware/系统签名与适配.md)。

## 5. 冲突处理

1. 录像中拍照 → 提示先停止录像  
2. 未登录 → 识图仅本地预览  
3. 低电 → `BatteryPolicy`：≤15% 红灯 + 提示；≤10% 禁录/禁 AI  
4. 录像 ↔ AI → `SessionPolicy`：录像中仅允许「停止录像」类指令；AI 忙时不可开录  
5. 夜视 → `NightVisionController` 按 `als_data` 自动切换 IR_CUT + `ir_led`

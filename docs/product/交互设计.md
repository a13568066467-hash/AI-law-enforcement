# 交互设计 — DSJ-ZECN6A1 执法记录仪

> 硬件：DSJ-ZECN6A1 · 本机 Android 主控 App

## 机身按键（映射见 `RecorderKeyDispatcher`）

| 按键 | 行为 | 反馈 |
|------|------|------|
| 录像键（F9 等） | 开始/停止录像 | 绿灯常亮 |
| 快门键（CAMERA 等） | 拍照 → 自动识图 | 相册更新 |
| SOS 键长按 | 应急演示场景 | 弹窗 + 云端 demo |

## 语音指令（AI 助手页 / 后续 ASR）

```
开始录像 / 停止录像
识别一下 / 拍一张
记录一下：今天三层验收通过
```

## App 内操作

| 页 | 职责 |
|----|------|
| 首页 | 本机状态、录像/拍照、SOS |
| 场景 | 九大工地场景演示 |
| AI 助手 | 文字/PTT 演示对话 |
| 相册 | 照片 + 识图结果 |
| 我的 | 巡查员注册/登录/设置 |

## 冲突处理

1. 录像中拍照 → 提示先停止录像
2. 未登录 → 识图仅本地预览
3. 低电策略 → 待 ZE69 电量 API 接入

## 1. 形态决策

### 1.1 选型结论

| 不采用 | 采用 |
|--------|------|
| 智能眼镜（与 PPE 冲突） | **胸牌夹相机**（默认） |
| 大屏 Android 执法终端（成本高、像警用装备） | **无屏 + LED + 语音 + App** |
| 类 GoPro 大方块（偏消费运动相机） | **扁平胸牌**，可兼帽夹 |

**参考行业：** 胸牌/无屏执法记录仪在巡检场景已普及（如市面 [胸牌类执法记录仪](https://www.besovideo.com/en/product?cId=2)）；本产品差异在 **AI 镜头朝前的轻量胸牌**，而非 4G 大屏手台。

### 1.2 产品形态一句话

**扁平胸牌相机**：正面广角镜头朝前，背面胸夹/帽夹；顶边三键；无屏；**胸挂默认**，配合语音与 AI 免提作业。

### 1.3 与「方块 GoPro」的关系

| 阶段 | 外壳 |
|------|------|
| **原型验证** | 可用简易方块/面包板仓（现有 BOM） |
| **对外演示 / V1** | **胸牌壳** 为默认外观目标 |
| 可选 | 方块壳 + GoPro 底座（次要 SKU） |

## 2. 外观规格（V1 目标）

### 2.1 外形尺寸

| 参数 | 目标值 | 说明 |
|------|--------|------|
| 外形 | **扁平圆角胸牌** | 长边横向佩戴 |
| 尺寸 | **约 48 × 38 × 18 mm** | 厚边含电池与夹具 |
| 重量 | **≤ 55 g**（含 2000mAh） | 全天胸挂可接受 |
| 镜头 | 正面偏上，φ8–10 mm 孔 + 保护圈 | OV5640 扩展模组 |
| 材质 | 原型 3D 打印 ABS/PLA | 量产 ABS+硅胶套 |
| 颜色 | 深灰/工程黄 | 耐脏、工地辨识 |

### 2.2 机身布局（胸牌正视）

```
                 顶边（窄边朝上时）
        ┌─────────────────────────────┐
        │ [AI]   [快门]   [电源]       │  ← 三键凸起，防手套误触
        ├─────────────────────────────┤
        │  ● 状态 LED                    │
        │       ◉ 镜头                  │  ← 朝前 POV
        │  (mic)              (mic)     │  ← 左右进音孔
        ├─────────────────────────────┤
        │      扬声器缝（侧向出音）       │
        └─────────────────────────────┘
                 底边：USB-C 充电口（橡胶塞 V1.1）

        背面：
        ┌─────────────────────────────┐
        │   胸夹 / 帽夹 一体卡扣        │
        │   （可换磁吸背板 P1）         │
        └─────────────────────────────┘
```

### 2.3 与 GoPro / 执法大屏的差异

| 项目 | GoPro / 消费运动相机 | 典型 4G 执法仪 | 本机 V1 |
|------|----------------------|----------------|---------|
| 体积 | 方块厚 | 常更大、带屏 | **扁胸牌** |
| 屏幕 | 有 | 3–5 寸屏 | **无屏** |
| 联网 | WiFi | 机身 4G | **BLE + 手机** |
| AI | 弱/无 | 平台录像为主 | **快门识图 + 语音助手** |
| 外观气质 | 运动 | 警用/安防 | **项目部巡检工具** |

## 3. 挂载方式

### 3.1 挂载矩阵

| 挂载 | 场景 | 视角 | V1 |
|------|------|------|-----|
| **胸挂夹** | 巡检、验货、双手作业 | 稳定前向 | ⭐⭐⭐ **默认** |
| **帽夹** | 安全帽/鸭舌帽 POV | 随头 | ⭐⭐ P1 套件 |
| 肩夹/磁吸 | 临时记录 | 略侧 | P1 |
| 三脚架 | 定点监视 | 固定 | P1 |
| GoPro 胸带 | 兼容旧习惯 | 同胸挂 | 可选配件 |

### 3.2 胸挂（默认）

- **织带 + 快拆**，主机背面 **J 型胸夹** 卡入  
- 镜头位于 **胸口偏上**，行走时对准操作面  
- 麦克风孔 **朝外**，建议 V1.1 加 **防风海绵套**  
- 与重载执法胸牌相比：**更轻、无屏、强调 AI 而非纯录像**

### 3.3 帽夹（P1）

- 弹性夹固定在帽檐前缘  
- 适合狭窄空间 **真 POV**  
- 需验证：扬声器在帽下是否听得清（必要时 V1.1 蓝牙耳机）

### 3.4 挂载件采购

| 物品 | 说明 | 参考价 |
|------|------|--------|
| 胸挂织带 + 快拆 | 运动相机通用 | ¥15–40 |
| 帽檐夹 | 小型相机夹 | ¥10–25 |
| 磁吸背夹 | 铁质临边 | ¥8–20 |
| 1/4 螺母座 | 三脚架 | ¥2–5 |
| 防风海绵套 | 双麦孔 | ¥5–15 |

## 4. 内部结构（XIAO 方案）

### 4.1 堆叠示意（自上而下）

```
顶盖（三键开孔）
├── 电源 / 快门 / AI 轻触键
主板仓
├── Seeed XIAO ESP32S3 + Sense 扩展座
├── OV5640 扩展模组（镜头从正面伸出）
├── INMP441 ×2（左右 Mic 孔，SD 并接 GPIO44）
├── MAX98357 + 8Ω 喇叭（侧缝出音）
├── BMI270（可选，V1 可不焊）
电池仓
├── 3.7V 2000mAh 软包 + 保护板
├── TP4056（USB-C 从底边引出）
├── 气凝胶垫：电池与主板隔热
底盖
├── 胸夹机构 / 散热孔（φ2 mm ×2 可选）
```

引脚与接线：[XIAO硬件接线.md](./XIAO硬件接线.md)

### 4.2 热与续航（2000mAh）

| 要点 | 做法 |
|------|------|
| 散热 | XIAO 散热片贴金属面；外壳内导热垫 |
| 隔热 | 电池与主板之间气凝胶 |
| 边充边录 | 底边 USB 外露；避免暴晒闭盖充电 |
| 待机 | 12h+ 目标（轻睡眠） |
| 对话 | 2–3h 连续 |
| 录像 | 45–90 min/充 累计 |

## 6. 环境与设计要点

| 要点 | V1 原型 | V1.1 方向 |
|------|---------|-----------|
| 防尘 | 进音/出音防尘网 | **IP54** |
| 防摔 | 圆角 + 镜头保护圈 | 硅胶套 |
| 防雨 | 不宣称防水 | 充电口胶塞 |
| 耐脏 | 深灰壳体 | 可换硅胶套 |
| 标识 | 正面小字「AI Field Cam」 | 项目部贴纸位 |

**不做 V1：** IP68、防爆、红外测温、机身大屏。

## 7. 原型实现路径

```
阶段 1  面包板 + XIAO + OV5640（功能验证，现有）
阶段 2  3D 打印「胸牌壳」— 优先扁平夹具，非大方块
阶段 3  胸挂/帽夹实场试戴 — 调 Mic 孔、按键高度、重量
阶段 4  定制 PCB 缩至胸牌尺寸（V1.1）
```

**3D 胸牌壳要点：**

- 背面一体 **胸夹** 或标准夹槽  
- 正面镜头孔按 OV5640 扩展座实测  
- 顶边三键 **12×12 / 6×6** 孔位  
- 侧面 **扬声器缝** 宽 8–12 mm  
- 底边 **USB-C** 开孔 + 走线槽

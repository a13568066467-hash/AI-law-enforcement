# AI 实地相机 — 项目总览（完整思路）

> 本文档汇总 **text1** 仓库的产品定位、技术路线、连接方式、云端 AI、代码编排与开发顺序。  
> 细节协议与规格见文末「文档索引」中的专项文档。

**版本：** V1 思路定稿 · 路线 1（手机 BLE 网关 + 零配置 App + 你们云端）

---

## 1. 产品是什么

**AI 实地相机（AI Field Cam）**：**胸牌夹相机**（无屏轻量），面向工地/巡检等实地作业。默认胸挂，**非眼镜**。

### 1.1 三大核心功能

| 功能 | 工人得到什么 | 典型触发 |
|------|--------------|----------|
| **录像** | 720p 现场留痕，在手机 App 相册回放 | 语音「开始/停止录像」；可选长按快门（V1.1） |
| **拍照** | 照片存入 App 相册 | 单击快门 |
| **AI 助手** | 语音对话、控制录像/拍照、**拍图后听 AI 解释**、**追问上一张图** | 双击 **AI 键**；语音「识别一下」 |

### 1.2 V1 明确不做

- 设备直连大模型（WiFi/4G 上云）  
- 工人在 App 里配置 API Key  
- 端侧 YOLO / 离线大模型  
- 长篇现场记录  
、录像中实时识物  

### 1.3 目标用户与部署

| 角色 | 行为 |
|------|------|
| **现场工人**（含农民工） | 只会：连蓝牙、按键、说话；**不配置 API** |
| **你们（产品方）** | 提供固件、App、**自有后端**、运维百炼密钥与套餐 |

## 2. 总技术路线（路线 1）

**一句话：** 设备只采集和播放；手机是网关；智能在你们云端；密钥工人看不见。

```
┌─────────────┐    BLE     ┌─────────────┐  HTTPS/WSS  ┌─────────────┐     API      ┌──────────┐
│  ESP32-S3   │ ◄────────► │  手机 App    │ ◄──────────► │  你们后端    │ ◄──────────► │ 阿里百炼  │
│  固件       │            │  零配置登录   │              │  A/B 调度    │              │ turbo/VL-8B │
└─────────────┘            └─────────────┘              └─────────────┘              └──────────┘
      │                          │                            │
   按键/麦/相机              相册/对话页                  ASR/TTS/鉴权
```

**为何不设备直连云？**  
工人不会配网配 Key；V1 优先交付与现有 `BLE协议.md` 一致

## 3. 三层分工

| 层 | 技术栈 | 负责 | 不负责 |
|----|--------|------|--------|
| **设备** `firmware/` | ESP-IDF 5.x、C、NimBLE、`esp_camera`、I2S、Opus | FSM 状态机、MJPEG 录像、JPEG 拍照、采麦、播 TTS、BLE 分包、电量/LED | 上网、ASR、LLM、识图推理 |
| **App** | **uni-app x**（`apptext/` · HBuilderX）+ `uni` 蓝牙 API | 登录、BLE、`session.uts` 编排、相册、调 API、执行 `ble_cmds` | 硬件驱动、存 API Key 到设置页 |
| **云端** | 自建服务 + 阿里百炼 | 鉴权、会话、`Router`、调 `qwen-turbo` / `qwen3-vl-8b-instruct`、ASR、TTS | 直接控 GPIO |

### 3.1 两个软件「中心」

| 中心 | 位置 | 原则 |
|------|------|------|
| **固件 FSM** | `firmware/main/app_fsm.c` | 按键、BLE 命令 → 统一 `glass_event_t` → `app_fsm_handle_event()`；模块间不绕过 FSM |
| **App 会话** | `apptext/services/session.uts` | 所有 BLE 与云端调用经此层；UI 页不直接写 GATT |

## 4. 连接与协议

### 4.1 设备 ↔ App：BLE GATT

- 设备：**BLE Peripheral**（NimBLE）  
- App：**BLE Central**  
- 规范：**[`BLE协议.md`](./BLE协议.md)**

| 特征 | 方向 | 用途 |
|------|------|------|
| A002 CMD_WRITE | App → 设备 | 控制命令 |
| A003 CMD_NOTIFY | 设备 → App | 事件通知 |
| A004 AUDIO_TX | 设备 → App | 麦克风 Opus（16 kHz，20 ms 帧） |
| A005 AUDIO_RX | App → 设备 | TTS Opus → 机身喇叭 |
| A006 IMAGE_TX | 设备 → App | JPEG 分片 |
| A007 VIDEO_TX | 设备 → App | 录像文件分片 |
| A008 SENSOR_NOTIFY | 设备 → App | 电量、STATE（0=IDLE 1=AI 2=CAPTURE 3=RECORD） |

**常用 CMD：**

| CMD | 含义 |
|-----|------|
| 0x01 | 开始录像 |
| 0x02 | 停止录像 |
| 0x03 | 拍照（App 侧可再接识图） |
| 0x04 / 0x05 | 开始/停止 AI 聆听 |

### 4.2 App ↔ 你们云端

| 类型 | 协议 | 用途 |
|------|------|------|
| 登录 | HTTPS | `POST /auth/login` → `worker_token` |
| 绑定 | HTTPS | `POST /device/bind` |
| 对话 | HTTPS | `POST /v1/chat`（ASR 文本入，intent + reply + ble_cmds 出） |
| 识图 | HTTPS | `POST /v1/vision`（JPEG base64） |
| 听写 | WebSocket | 流式 ASR（上行 Opus/PCM） |
| 播报 | HTTPS 或 WSS | TTS → Opus 回 App |

App **内置**正式环境 API 域名；**不出现**「填写 API Key」界面。

### 4.3 你们云端 ↔ 阿里百炼

| 能力 | 模型（已定） | 备注 |
|------|--------------|------|
| Agent-A / Agent-B | **qwen-turbo** | 中国内地（北京）地域；新人免费额度，建议「用完即停」 |
| 拍图解释 | **qwen3-vl-8b-instruct** | 与 turbo 额度分开 |
| ASR | Paraformer 实时 | 百炼/灵积 |
| TTS | CosyVoice 等 | 播报链路 |

密钥仅存在于**后端环境变量**。

### 4.4 云端结果如何回到设备

| 结果类型 | 路径 |
|----------|------|
| **语音播报** | 云 TTS → App → BLE **A005 AUDIO_RX** → `audio_out` → 喇叭 |
| **控制设备** | 云解析 intent → 响应 `ble_cmds` → App 写 **A002** → FSM |
| **照片/录像** | 设备 → BLE → **App 相册**（一般不回灌设备；无屏） |

## 5. 云端 AI：双 Agent A+B

> 专项说明：[**云端AI代理.md**](./云端AI代理.md)

| Agent | 模型 | 职责 |
|-------|------|------|
| **A** | qwen-turbo | 控制意图（录像/停录/拍照识图）+ **短答**（≤2 句） |
| **B** | qwen-turbo | **追问上一张图**（仅用 `last_explanation`，禁止编造读数） |
| **Vision** | qwen3-vl-8b-instruct | 快门后识图解释，写入 `last_explanation` |

**调度（Router）：**

```
有 last_explanation 且用户话像追问？ → Agent-B
否则                                 → Agent-A
```

追问关键词示例：`刚才|上一张|那个|读一下|多少|型号|参数|什么意思`

**Agent-A intent → BLE：**

| intent | App |
|--------|-----|
| start_recording | 0x01 |
| stop_recording | 0x02 |
| capture_and_explain | 0x03 + `/v1/vision` |
| chat | 仅 TTS |

**规则：** 仅 A 可输出控制 intent；B **不得**触发录像/拍照命令。

## 6. 三大功能数据流

### 6.1 录像

```
触发（语音 intent 或后续按键）
  → App 发 CMD 0x01 → FSM = RECORD
  → MJPEG 720p@15fps 写 Flash，红灯
  → 停止：CMD 0x02 → NOTIFY 0x82 → VIDEO_TX 分片
  → App 相册播放/导出
```

**互斥：** 录像中一般不进入 AI_ASSIST（或提示先停录）。

### 6.2 拍照与识图解释

```
单击快门 / CMD 0x03 / 「识别一下」
  → FSM = CAPTURE → JPEG → IMAGE_TX → App 相册
  → POST /v1/vision (qwen3-vl-8b-instruct)
  → last_explanation 写入会话
  → TTS → AUDIO_RX → 喇叭播报
  → 用户可继续问 → Router → Agent-B
```

**不做扫码分支；** 识图统一走 Vision。

### 6.3 AI 语音助手

```
双击 AI 键
  → FSM = AI_ASSIST，NOTIFY 0x84，开始 AUDIO_TX
  → App ASR 流式上传
  → POST /v1/chat → Router → A 或 B
  → 若 intent：ble_cmds；若 reply：TTS → AUDIO_RX
  → VAD 静音约 5s → STOP_AI → IDLE
```

## 7. 固件状态机

```
              ┌─────────┐
              │  IDLE   │
              └────┬────┘
     双击 AI      │      单击快门        开始录像
         ┌───────▼───────┐   ┌────▼────┐   ┌────▼────┐
         │  AI_ASSIST    │   │ CAPTURE │   │ RECORD  │
         └───────────────┘   └─────────┘   └─────────┘
```

| 状态 | SENSOR STATE | 说明 |
|------|--------------|------|
| IDLE | 0 | 默认 |
| AI_ASSIST | 1 | 推麦；可拍照打断 TTS |
| CAPTURE | 2 | 短态，传图后回 IDLE |
| RECORD | 3 | App 不应在未停录时 START_AI_LISTEN |

实现参考：`firmware/main/app_fsm.c`、`firmware/main/button.c`。

## 8. 算法与技术选型（是什么、放哪）

| 技术 | 类型 | 层级 | 用途 |
|------|------|------|------|
| MJPEG | 视频存储 | 设备 | 录像，省 CPU |
| JPEG | 图像压缩 | 设备 | 拍照上传 |
| Opus | 音频编解码 | 设备↔App | AI 对话带宽友好 |
| VAD / AEC / 降噪 | 信号处理 | 设备 | 拾音与结束会话 |
| FSM | 状态机 | 设备 | 业务互斥 |
| **standby_mgr** | 省电策略 | 设备 | AI 5s 无活动关麦；IDLE 超时轻睡眠 |
| BLE GATT | 通信 | 设备↔App | 唯一物理链路 |
| 规则 Router | 调度逻辑 | 云端 | 选 A 或 B |
| qwen-turbo | 大语言模型 | 云端 | A/B 对话与 intent |
| qwen3-vl-8b-instruct | 多模态模型 | 云端 | 拍图解释 |
| Paraformer | ASR | 云端 | 语音转文字 |
| CosyVoice 等 | TTS | 云端 | 播报 |

**不采用：** 端侧 YOLO、ZXing 扫码、设备侧 LLM。

## 10. 工人侧使用流程（零配置）

```
1. 项目部已在你们后台开通账号
2. 工人安装 App → 手机号/扫码登录（无 API 设置页）
3. 打开蓝牙 →「连接相机」→ 自动绑定 device_id
4. 双击 AI → 听「我在」→ 说话
5. 单击快门 → 听识图解释（若开启）
6. 说「开始录像」→ 红灯 → 停录后在相册查看
```

实施人员最多协助：**登录 + 点连接**。

## 11. 开发顺序（按依赖，勿并行三条业务线）

| 阶段 | 目标 | 里程碑 |
|------|------|--------|
| **P0** | 后端骨架：登录、`/v1/chat`（A/B）、`/v1/vision`；可先 mock TTS | App 带 token 调通 |
| **P1** | BLE + 拍照：`IMAGE_TX` → App 相册 | 手机收到一张照片 |
| **P2** | AI 闭环：`AUDIO_TX/RX` + ASR + A + TTS | 双击能对话 |
| **P3** | 识图：`qwen3-vl-8b-instruct` + 播报 + `last_explanation` | 快门后能听解释 |
| **P4** | 录像：MJPEG 5 min + `VIDEO_TX` | 连续录不崩 |
| **P5** | 语音控制：A 的 intent → CMD | 「开始录像」能执行 |
| **P6** | ToB：绑定、套餐、日志、额度告警 | 项目部可运维 |

无硬件：先用 **`demo-web/`** 验证状态与话术；固件编译目录 **`firmware/`**。

## 12. 测试与验证

| 方式 | 命令 / 操作 |
|------|-------------|
| 主机 FSM 回归 | `python tools/fsm_host_test.py` |
| 固件自测 | menuconfig 开启 FSM self-test，烧录看 `15/15 passed` |
| Web Demo | 打开 `demo-web/index.html` |
| 低电喇叭 | menuconfig 模拟电量 9% + 接 MAX98357 |

按键要点：电源长按 3s；AI 双击开/关；录像中长按快门 1s 停录；**先** ≤15% 每 **120s** 喇叭提醒，**再** ≤10% 禁开录/AI（见 [电量监测.md](./电量监测.md)）。
